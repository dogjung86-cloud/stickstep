# g2u7l8f1 전동기의 구조와 원리 (검산 메모)

- 자리: g2u7l8 코일이 받는 힘, 정리 카드 2 「전동기」 자세히, 소제목 '왜 돌까요?' 문단 바로 뒤('실험과 이어 봐요' 앞). `sciFigMore`.
- 근거: 책 268쪽 그림 Ⅶ-15(전동기의 구조와 원리). 갈라진 고리와 고리에 닿는 막대는 책 그림에 그려져 있지만 이름과 설명이 없어, 생김새를 그대로 풀어 쓴 이름표로 달았다(사용자가 이 그림을 넣기로 함).

## 담은 과학 사실
- 좌표: x 오른쪽(N에서 S, 자기장 방향), y 위, z 보는 사람 쪽(회전축 방향). 위 큰 그림은 오른쪽 앞 위에서 비스듬히 내려다본 정사영(화면 오른쪽 위가 뒤쪽, 앱 전동기 랩과 같은 약속).
- 왼쪽 N극(빨강), 오른쪽 S극(파랑) 자석, 극의 면은 회전축을 중심으로 한 원통면(반지름 56)으로 둥글게 팠다. 자기장 화살표 셋은 N에서 S로.
- 네모 코일(반 너비 42, 반 깊이 40)은 수평으로 누워 있고 회전축이 가운데를 앞뒤로 지난다. 앞쪽 축에 두 쪽으로 갈라진 구리 고리(반지름 8, 틈 16°), 양옆에 고정된 흑연 막대 둘이 놋쇠 받침에 눌려 닿는다.
- 전류의 길(끊김 없이): 전원 (+)극 → 빨간 전선 → 오른쪽 막대 → 오른쪽 고리 쪽 → 코일 오른쪽 변(앞에서 뒤로, −z) → 뒷변(오른쪽에서 왼쪽으로) → 왼쪽 변(뒤에서 앞으로, +z) → 왼쪽 고리 쪽 → 왼쪽 막대 → 검은 전선 → (−)극.
- 힘(손바닥으로 검산, 네 손가락 N → S = +x, 엄지 = 전류, 손바닥이 미는 쪽 = 힘. 벡터곱으로도 확인): 왼쪽 변 전류 +z → (0,0,1)×(1,0,0) = (0,1,0) 위. 오른쪽 변 전류 −z → 아래. 그래서 앞에서 보면 시계 방향으로 돈다(보라 원호: 앞쪽에서 왼쪽 변 자리를 아래에서 위로).
- 자기장과 나란한 뒷변에는 힘을 그리지 않았다.
- 고리의 두 쪽은 코일과 함께 돌고, 막대는 돌지 않는다. 고리의 틈은 코일 면과 수직인 방향(0°일 때 위아래)에 있어, 코일 면이 자기장과 수직으로 서는 90°에서 두 막대가 틈을 지난다.
- 아래 띠(작은 그림 셋, 같은 시점을 줄여 그림): 코일의 두 변을 주황(처음 왼쪽 변), 보라(처음 오른쪽 변) 테두리로 구별하고, 각 변에 이어진 고리 쪽과 앞쪽 전선도 같은 색. 막대는 왼쪽 −, 오른쪽 +.
  - 0°: 주황 변이 왼쪽, 전류 앞으로(+z), 힘 위. 보라 변 오른쪽, 뒤로, 힘 아래.
  - 90°(앞에서 시계 방향으로 90° 돈 자리): 주황 변이 위, 보라 변이 아래. 두 막대가 고리의 틈에 닿아 전류가 흐르지 않고 힘도 없다. 코일은 돌던 기세로 넘어간다('틈을 지나요').
  - 180°: 보라 변이 왼쪽에 와서 오른쪽 막대(+)에는 주황 쪽 고리가 닿는다. 왼쪽 변(보라)에 다시 앞으로 흐르는 전류, 힘 위. 오른쪽 변(주황) 뒤로, 힘 아래. 그래서 같은 쪽(시계 방향)으로 계속 돈다.
- 작은 그림은 명세의 '앞에서 본' 모습 대신 같은 시점을 줄인 비스듬한 그림이다. 정면에서는 변이 점으로 보여 전류의 방향을 화살표로 보일 수 없고(⊙, ⊗ 기호는 이 과정 책에 없음), 비스듬한 그림이면 위 큰 그림과 바로 견줄 수 있어서다.
- 전류의 방향이나 자석의 극을 바꾸면 반대로 돈다(정리 카드 글이 맡음, 그림에는 넣지 않음).

## 계산과 기하
- 투영: 큰 그림 가로축 돌림 0.36 rad, 내려다보는 각 0.66 rad, 1.24 배. 작은 그림 0.36 rad, 0.5 rad, 0.6 배.
- 가림 검산: 자석 높이를 ±21로 낮게 잡아, 코일 오른쪽 변에서 보는 쪽으로 그은 선이 S극 안쪽 면(x = 56)에 닿을 때 높이가 21보다 높다(앞 위에서 S극 너머로 코일이 보인다). 그래서 두 자석을 먼저, 코일을 나중에 그린다. 왼쪽 막대는 고리보다 뒤쪽이라 고리보다 먼저, 오른쪽 막대는 고리보다 나중에 그린다.
- 고리 두 쪽의 가운데 각: 변 A 쪽 180° − φ, 변 B 쪽 −φ(앞에서 볼 때, 0 = 오른쪽). 막대(0°, 180°)가 어느 쪽에 닿는지를 각으로 계산해 전류와 힘의 방향을 정했다.

## 라벨

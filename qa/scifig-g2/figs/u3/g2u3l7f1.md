# g2u3l7f1 물결파의 모습 (검산 메모)

- 자리: g2u3l7 파동의 발생과 전달, [5] 정리 카드 1 「파동의 모습」 자세히, 소제목 '네 가지 이름' 바로 뒤, '실험에서는' 앞.
- 근거: 책 121쪽 그림 Ⅲ-15 물결파의 발생과 전파, 126~127쪽 중단원 정리(파동의 모습). 도입(g2u3-float)의 낚시찌와 이어진다.

## 담은 과학 사실
- 수면 높이 z(r) = −A sin(2πr/λ), r = 막대가 두드리는 점에서 거리. 위쪽 수면의 동심원과 앞쪽 단면이 같은 식, 같은 가로 축척이다
  (단면의 마루 자리에서 위쪽 마루 고리가 시작된다).
- 단면은 두드리는 점을 지나는 반지름 방향으로 잘랐다. 진동 중심(점선)에 대해 위아래가 대칭인 매끈한 물결이고, 보이는 두 파장 안에서 진폭이 같다
  (퍼질수록 낮아지는 효과는 그리지 않았다).
- 파장 = 마루에서 이웃 마루(위) = 골에서 이웃 골(아래), 둘 다 88 px. 진폭 = 진동 중심에서 마루까지(17 px) = 진동 중심에서 골까지(17 px).
- 회색 보조 자: 마루에서 이웃 골까지 가로 44 px = 파장의 절반, 마루에서 골까지 높이 34 px = 진폭의 두 배.
- 낚시찌는 위쪽 수면의 마루 고리(r = 1.75λ, z = +A) 위에 있고, 곁에는 세로 양쪽 화살표만(가로 화살표 없음).
- 파동의 진행 방향 화살표는 두드리는 점에서 바깥쪽(반지름 방향).
- 세로는 키워 그렸다(진폭 17 px, 파장 88 px). 두 진폭 자는 같은 길이다.

## 기하(설계 px, 340 × 346)
- 두드리는 점: 앞 모서리 x = 30, 진동 중심 y = 206. 안쪽 방향은 0.52배로 줄여 위에서 비스듬히 본 모습(정사영).
- 단면의 마루: x = 96, 184, 272(r = 0.75λ, 1.75λ, 2.75λ). 골: x = 52, 140, 228(r = 0.25λ, 1.25λ, 2.25λ).
- 자: 파장(위) 184 → 272, 파장(아래) 140 → 228, 진폭(마루) x 96, 진폭(골) x 52, 회색 가로 184 → 228, 회색 세로 x 240(y 189 → 223).
- 위쪽 수면은 화면 열마다 앞에서 안쪽으로 걸으며 칠하는 높이장 그림이라 앞의 물결이 뒤를 가린다. 음영은 물결 기울기(법선)와 왼쪽 위 빛으로 셈한다.

## 라벨
마루, 골, 진동 중심, 파장(두 개), 진폭(두 개), 파동의 진행 방향, 마루에서 골까지 가로 = 파장의 절반, 마루에서 골까지 높이 = 진폭의 두 배.

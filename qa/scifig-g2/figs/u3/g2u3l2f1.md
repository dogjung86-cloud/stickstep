# g2u3l2f1 빛의 굴절, 네 줄기 (검산 메모)

- 자리: g2u3l2 빛의 굴절, [2] 개념 「꺾이는 빛에 이름을 붙여요」, 용어 카드 (2) 입사각과 굴절각 바로 뒤, 알림 (3) 앞.
- 근거: 책 101쪽 그림 Ⅲ-3 빛의 굴절, 100쪽 해 보기(사각 수조, 우유, 향 연기, 레이저 지시기). 값은 정리 카드 0의 '약 15°, 29°, 41°'와 같다.

## 담은 과학 사실(스넬 법칙, 공기 1.00 → 물 1.33)
- sin(굴절각) = sin(입사각) / 1.33: 0° → 0°, 20° → 14.90°, 40° → 28.90°, 60° → 40.63°. 그림의 표는 약 15°, 약 29°, 약 41°.
- 굴절 광선은 법선의 반대쪽으로 나아가며 법선 쪽으로 다가간다. 40° 줄기의 굴절 광선(28.90°)은 회색 점선 '꺾이지 않았다면 갈 길'(40°)보다 법선에 가깝다.
- 굴절각은 늘 입사각보다 작고 입사각과 함께 커진다. 각은 모두 법선에서 잰다. 수직 줄기(0°)는 꺾이지 않고 법선과 겹친다.
- 경계면에서 되돌아 나오는 약한 반사 빛은 그리지 않았다(굴절만 다루는 그림).

## 명세와 다르게 한 점(까닭)
- 명세는 네 줄기 모두 왼쪽 위에서 들어오게 했지만, 그러면 60° 줄기의 굴절 광선(40.63°)이 40° 줄기의 '꺾이지 않았다면 갈 길'(40°)과 0.63°밖에
  벌어지지 않아 두 선이 한 줄로 겹친다(140 px 길이에서 약 1.5 px 차이). 그래서 이름표를 다 단 40° 줄기는 랩의 레이저 자리인 왼쪽 위에서,
  견줌용 가는 세 줄기(0°, 20°, 60°)는 오른쪽 위에서 같은 점 O로 들어오게 했다. 법선을 기준으로 한 각과 꺾이는 정도는 그대로다.

## 기하(설계 px, 340 × 312)
- 수면 y = 160, O = (150, 160). 법선: x = 150, y 18 ~ 298 점선.
- 40° 줄기: 레이저 앞끝 = O + 124 × (−sin 40°, −cos 40°) = (70.3, 65.0). 굴절 광선 끝 = O + 140 × (sin 28.90°, cos 28.90°) = (217.6, 282.6).
  꺾이지 않았다면 갈 길: O + 140 × (sin 40°, cos 40°) = (240.0, 267.2).
- 가는 줄기: 오른쪽 위 반지름 124에서 O로, O에서 왼쪽 아래 반지름 124로(각 0°, 14.90° / 20°, 40.63° / 60°).
- 각 호 반지름 54: 입사각(앰버) 화면 각 −130° → −90°, 굴절각(시안) 61.10° → 90°.

## 라벨
법선, 공기, 물, 입사 광선, 굴절 광선, 입사각 40°, 굴절각 약 29°, 꺾이지 않았다면 갈 길, 0° → 0°, 20° → 약 15°, 60° → 약 41°.

# g2u2l6f1 암석의 순환이 일어나는 곳 (검산 메모)

- 자리: g2u2l6 암석의 순환, [3] 개념 「암석의 순환, 끊임없이 변하는 암석」의 용어 카드 (2) 암석의 순환 뒤, note (3)(정해진 방향 없음) 앞.
- 근거: 책 71쪽 그림 Ⅱ-15(암석의 순환)와 본문, 용어 카드 (2)의 다섯 말, CycleLab(rockLabs.ts)의 마디와 길(GO 표).
  책 그림은 화산 풍경 위에 추상 도식을 얹은 것이고, 이 그림은 "어디에서 일어나는가"를 자리로 보인다.

## 담은 과학 사실
- 풍경(산에서 바다까지): 왼쪽 끝 화산(용암, 연기, 마그마에서 올라온 가는 통로), 변성암과 화강암이 드러난 산(꼭대기에 부서진 바위 조각),
  산비탈에서 평야를 지나 바다로 흐르는 강(자갈과 모래), 바다 밑에 수평으로 얇게 쌓인 퇴적물, 그 아래 수평 층리의 퇴적암,
  더 깊은 곳의 변성암(산 아래에서는 지표까지), 가장 깊은 곳에서 녹아 생긴 마그마, 위로 올라와 굳은 화강암(심성암) 덩어리.
- 깊이 차례(위에서 아래): 퇴적물·퇴적암 → 변성암 → 녹는 곳과 마그마. 퇴적물은 물 밑에 수평으로, 아래가 먼저.
- 다섯 자리 이름표의 색은 CycleLab 마디 색: 퇴적물 #E2B85A, 퇴적암 #C9A27A, 변성암 #B197FC, 마그마 #FF7A45, 화성암 #9AA5B1. 암석 결에도 같은 빛을 옅게 섞었다.
- 큰 고리(굵은 화살표, 실제 길대로): 화성암 → (지표로 드러남) → 산의 지표 → (잘게 부서짐, 강을 따라) → 퇴적물 → (다져지고 굳어짐) → 퇴적암
  → (열과 압력을 받음) → 변성암 → (녹음) → 마그마 → (식어서 굳어짐) → 화성암.
- 지름길(점선): 화성암 → 변성암(열과 압력을 받음), 변성암 → 산비탈의 지표(지표로 드러남, 이어서 잘게 부서짐으로 퇴적물), 퇴적암 → 마그마(녹음).
  CycleLab의 GO 표(ign: heat → met, met: break → sedi, sed: melt → mag)와 같다. 같은 일로 같은 자리에 닿는 두 화살표는 과정 이름 하나를 함께 쓴다
  (열과 압력을 받음, 녹음, 지표로 드러남). 캡션에 "점선은 중간 단계를 건너뛰는 길"이라고 밝혔다.
- 과정 이름은 책과 개념 카드의 다섯 말 그대로이고 '지표로 드러남'만 더했다. 깊이와 가로는 실제 비율이 아님을 그림 아래에 밝혔다.

## 기하
- 단면 x 6~334, y 6~390. 해수면 y 98, 해안 x 226, 바다 밑바닥 최대 y 134, 퇴적물 두께 10 px, 퇴적암 아래 경계 y ≈ 208(산 쪽으로 솟아 산 전체가 변성암),
  마그마 위 경계 y ≈ 306. 화강암 덩어리 x 78~132(위) → 90~118(아래), 산꼭대기 (104, 37).
- 이름표 자리: 퇴적물 (288, 139), 퇴적암 (288, 186), 변성암 (282, 254), 마그마 (226, 350), 화성암 (100, 206).

## 라벨
퇴적물, 퇴적암, 변성암, 마그마, 화성암, 잘게 부서짐, 다져지고 굳어짐, 열과 압력을 받음, 녹음, 식어서 굳어짐, 지표로 드러남, 강, 바다,
깊이와 가로 길이는 실제 비율이 아님. 화산은 이름표 없이 그림으로만 둔다.

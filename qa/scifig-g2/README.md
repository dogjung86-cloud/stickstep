# 중2 과학 개념·정리 그림 (scifig-g2)

중2 과학 여덟 단원의 개념 스텝("과학 용어 정복하기")과 정리 카드의 자세히(more)에 넣는 정밀 그림을 코드로 그린다.
교과서와 과학 도감 수준을 목표로 한다: 실제 구조와 비율, 왼쪽 위 빛의 입체 명암, 재질과 질감, 자른 면, 과학 관례 색.
이미지 생성 모델과 발주는 쓰지 않는다. 블렌더도 쓰지 않는다.

## 구조

```
qa/scifig-g2/
  build.mjs        그림을 헤드리스 크롬에서 그려 public/scifig/g2/<단원>/<키>.webp 로 굽고, sciFigG2.ts 의 그림 표를 다시 쓴다
  check.mjs        앱 검사: 그림이 실린 스텝을 폰(390×700)과 넓은 화면(1180×760)에서 열어 로드, 한 화면 높이, 페이지 오류를 본다
  sheet.mjs        그림 시트(폰 카드 모양으로 늘어놓은 PNG). --bare 는 캡션 없이(검산을 맡길 때)
  kit/             브라우저 쪽 그리기 도구
    paint.mjs      고해상도 캔버스, 선형 공간 색 계산, 화소 단위 음영(shade), 입체 구(sphere), 그림자, 그라데이션, 바탕 판(plate)
    noise.mjs      씨앗 노이즈(심플렉스 2D·3D, fbm, 능선), 세포 노이즈(보로노이)
    cells.mjs      세포 단면(둥근 다각형, 반투명 세포질, 세포벽), 엽록체
    svg.mjs        라벨(흰 할로), 지시선(끝점), 굵은 과정 화살표, 가는 광선 화살표, 각도 호, 패널 꼬리표
  figs/<단원>/<키>.mjs   그림 하나. export const meta = { key, w, h, alt }, export default async function draw(root, kit)
  figs/<단원>/<키>.md    검산 메모: 담은 과학 사실, 기하 수치, 근거 쪽(그림마다 반드시)
```

- 키는 `g2u<단원>l<레슨>f<번호>`(예: g2u4l3f1). 조사 목록은 `output/sci-figures/g2/candidates.md`.
- 앱은 `src/content/g2/sciFigG2.ts`의 `sciFig(키, alt, cap)`(개념 스텝 그림 블록)과 `sciFigMore(키, alt, cap)`(정리 카드 more 안 HTML)만 쓴다.
  alt와 cap의 정본은 단원 글 파일이다. 그림 표(키 → 폴더, 가로, 세로)는 빌드가 다시 쓰니 손으로 고치지 않는다.

## 다시 그리기

```
node qa/scifig-g2/build.mjs                      # 모든 그림
node qa/scifig-g2/build.mjs g2u4l3f1 g2u5l1f1    # 고른 그림만
node qa/scifig-g2/build.mjs g2u4l3f1 --png=<폴더>  # PNG도 함께(눈검수)
node qa/scifig-g2/sheet.mjs <출력 png> [키 …]     # 그림 시트
PORT=<dev 포트> node qa/scifig-g2/check.mjs [캡처 폴더] [키 …]
```

- 크롬은 `playwright-core`의 `channel: "chrome"`(설치된 크롬)으로 띄운다. 라벨 글꼴은 Pretendard를 CDN에서 받으므로 인터넷이 필요하다.
- 화소 밀도 3(설계 폭 340 px → 1020 px), webp 품질 0.84. 한 장 대략 200 KB 이하를 지킨다(빌드가 230 KB 넘으면 알린다).

## 그리는 규칙

- 설계 폭 340 px. 폰 카드에서 그림은 약 312 px로 보이니(카드 안쪽 여백 16 px) 글자는 13.5 px 이상으로 쓴다(표시 12 px 이상). 라벨은 흰 할로.
- 높이는 대략 420 px 이하(폰 한 화면 안, 캡션까지). 넓은 화면에서는 노트 칸에서 약 437 px 폭으로 커진다.
- 빛은 왼쪽 위. 평면 아이콘, 균일한 검은 외곽선, 클립아트 느낌 금지. 재질은 그라데이션, 화소 음영, 노이즈 질감으로.
- 정확성 최우선: 기하(각, 방향, 개수, 비율)는 계산으로 정한다. 자기장, 광선, 입자 배열은 식으로 그린다.
- 색은 그 단원 랩과 같게(예: Ⅴ 기체 색 kit.ts, Ⅶ N극 #E0503A·S극 #3D8FE8, Ⅳ 원자핵 빨강·전자 파랑 chemKit).
- 라벨과 캡션은 그 스텝까지 학생이 이미 만난 말만 쓴다(용어 선경험 원칙). 대시 금지, '교과서' 금지.
- 천체(태양, 행성, 달, 별)의 겉면은 그리지 않는다(실사 사진). 궤도, 위치, 축척 도해만 코드로.
- 그림마다 같은 자리의 `<키>.md`에 검산 메모를 남긴다.

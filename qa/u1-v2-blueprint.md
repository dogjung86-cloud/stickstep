## 5. 그림 배선 — 신작 9종 + 재사용 2종

신작은 파일럿 단계에서 스테이징 파일 로컬 함수로 저작하고, 이식 때 `ui/examFigures.ts` 말미

1. **IF** `inquiryFlowFig(o: { steps: string[]; blank?: number; loop?: [number, number]; wrong?: number })`
   탐구 과정 흐름도. 세로 상자 사슬 + 아래 방향 화살표, `blank` 인덱스는 ㉠ 점선 상자,
   `loop`는 되돌아가는 곡선 화살표(라벨 "고쳐서 다시"), `wrong`은 잘못 놓인 칸 표시용 강조 없음
   (강조하면 정답 인쇄 — 판독은 학생 몫). 상자 텍스트 한글 ≤ 7자.
2. **PT** `planTableFig(o: { rows: [string, string][]; blank?: number; caption?: string })`
   탐구 계획표(행 라벨 | 내용 2열, 라벨 열 고정폭 96, 빈칸 행은 ㉠ 점선 셀). 셀 한글 ≤ 13자
   (svgTable 2열 한도 계승 — 초과 시 오버플로).
3. **VT** `variableTableFig(o: { items: string[]; marks: ("same" | "diff" | "q")[] })`
   조건별 "같게 / 다르게" 배정 표(3열: 조건 · 같게 · 다르게에 ✓ 마크, `q`는 ㉠ 빈칸).
   **조작 변인은 언제나 1행만 diff**(과학 규칙 검산 ①).
4. **CG** `resultLineFig(o: { xTicks: string[]; series: { name; color; points: number[] }[]; yMin; yMax; yStep; yLabel; xLabel })`
   집단별 꺾은선 결과 그래프. **정답 판독값은 반드시 눈금선 위**(눈금 사이 값 출제 금지) ·
   가이드 점선 금지(g2u2 ② 계보) · 레슨 dataGraph 수치·x눈금 구성 회피.
5. **BR** `resultBarFig(o: { bars: { label: string; value: number }[]; yMax; yStep; yLabel; unit? })`
   막대 결과 그래프. 값 라벨은 인쇄하지 않는다(막대 높이 판독이 과제 — 인쇄하면 장식).
6. **EX** `setupPairFig(o: { left: SetupSpec; right: SetupSpec })`
   실험 장치 (가)(나) 2패널 모식도(용기·받침·측정 도구·조건 표시). 다른 조건만 시각적으로
   구분되게 그리고 **조건 이름은 라벨로 인쇄하지 않는다**(판독 과제 보존).
7. **CH** `chainFig(o: { cells: string[]; blank?: number })`
   원리 → 기술 → 기기 → 문명 사슬(가로 4칸 + 화살표, `blank`는 ㉠ 점선 칸). 칸 한글 ≤ 8자.
8. **TL** `timelineFig(o: { events: { era: string; label: string }[]; hide?: number[] })`
   문명 연표(가로 시간축 + 사건 카드, `hide`는 라벨을 ㉠㉡으로 가림). **연도 수치는 시대 구간
   표기만**(직접 회상 금지 — §0 수치 취급).
9. **DB** `debateFig(o: { a: { name: string; claim: string }; b: { name: string; claim: string } })`
   두 학생 주장 말풍선 2개(좌·우 대비, 이름표는 가상 학생명). 주장 텍스트 한글 ≤ 34자(2줄).

## 8. 저작·검증 체크리스트 (파일럿·확대 공통)

1. **자료 의존 검산** — 그림·표·자료 상자를 가리고 문항을 읽었을 때 답이 나오면 장식이다. 장식이면
   자료를 빼고 무자료 화이트리스트로 재분류하거나 과제를 자료 판독으로 바꾼다.
2. **교차 유출 스캔(이 단원 1순위 위험)** — 주장-근거 지문·비교표·설명 카드가 **다른 문항의 정답을
   산문으로 선언**하기 쉽다(g2u2 v2 검산이 잡은 유형, 기계 스캔 불검출). 같은 사진 2문항 쌍 ·
   같은 헬퍼 군집 · dbox 지문끼리를 저작 직후 메인이 1차 대조하고 검산 에이전트가 2차로 훑는다.
3. **같은 사진·같은 헬퍼 군집 대조** — 질문과 정답이 전부 다른지, 한쪽 문두가 다른 쪽 정답을
   명명하지 않는지 확인(u7 v2 349·323 사고형).
4. **레슨 앵커 grep** — 저작 후 §2의 금지 문구·수치·보기 세트를 파일 단위로 검색한다.
5. **오답 격파의 정직성** — 오답 발생 원인을 지어내지 말고 "이 보기를 자료에 대 보면 어긋난다"는
   **검증형 서술**로 쓴다(m2u2 ⑥ 확립).
6. **절대어 사용 규율(2026-08-01 개정 — 검산 지적 반영)** — 실측 최다 오답 문법이 절대어
   ("~만 / 모두 / 전혀 / 못한다")지만, **정답 보기에는 절대어를 쓰지 않는다**(절대어 = 오답이라는
   메타 전략이 통하면 과제가 붕괴 · 부정형에서 "옳지 않은 것"이 정답이어도 마찬가지).

## 13. 공유 파일 사고 기록 (2026-08-01 · examFigures.ts 섹션 소실과 복구)

**사고**: 이식 생성기가 `examFigures.ts`에서 **"내 시작 마커 ~ 파일 끝"을 통째로 교체**하는 방식이라,
첫 실행 뒤 다른 세션들이 파일 끝에 append한 **u3 v2 헬퍼 11종 · u4 v2 헬퍼 22종을 두 번째 실행이
삼켰다**(tsc가 `has no exported member`로 적발). g2u7 v2 ⑥의 "정규식 게으른 확장" 사고와 같은 계열.

**복구**: 두 세션 모두 **스테이징(qa/u3v2-pilot.ts · qa/u4v2-pilot.ts)에 헬퍼 원본이 남아 있어**
각 세션의 build 스크립트와 동일한 승격 변환을 1회성 스크립트로 재적용해 전량 되살렸다
(tsc 통과 확인 · 타 세션 레슨 파일은 건드리지 않음).

**재발 방지(확정 관행)**:
① 공유 파일의 섹션 교체는 **시작 마커와 종료 마커 사이만** 바꾼다. 종료 마커가 없으면
   **throw로 중단**(다른 섹션 삼킴 위험을 조용히 넘기지 않는다).
② "마커 이후 전부"(`MARK + [\s\S]*$`) 패턴은 **동시 세션 환경에서 금지** — u4 v2 스크립트는 이미
   "다음 섹션 마커 직전까지"로 고쳐져 있었고 그래서 안전했다.
③ 공유 파일을 건드리는 생성기를 처음 돌린 뒤에는 **반드시 tsc로 전 파일 참조를 확인**한다
   (이 사고는 렌더·검사기에서는 잡히지 않고 tsc에서만 드러났다).

# 사회 Ⅻ(s1u12 인권과 기본권) 발주 — 스틱맨 개념 컷 7장(public/soc/cuts) + 만화 「당연한 것들의 역사」 4컷(public/comics/s1u12l1)
# 컷·만화 모두 "이미지 안 글자 절대 금지". 만화 컷은 앱이 한글 말풍선을 얹는 하이브리드라
# 인물이 입을 벌리고 손짓하는 "말하는 연기"만 그리고, 인물 머리 위쪽 1/3 여백을 넉넉히 남긴다.
# ★ 이 단원 눈검수 특칙(인권 단원 가드 — Ⅶ 차별 가드 준용 + 확장): 기존 항목(글자 0·의미 정확·손가락 5개·인물 존엄)에 더해
#   **비침해 검수** — 인권 침해 장면 재현·피해자 클로즈업 절대 금지: 침해·구제는 방패·저울·문·서류 소품으로만 표현,
#   **무표지 검수** — 특정 집단 표지 금지(휠체어·피부색 구분·머리카락·치마 등 0 — 다양성은 안경·모자·가방·앞치마 같은 소품으로),
#   **비폭력 검수** — 무기·전투·수갑·감옥·국기·구호 팻말 절대 금지(농기구도 들지 않음 — 바구니·보따리만),
#   **만화 존엄 특칙** — 과거 신분제 컷의 일하는 사람들은 작게(원경) 그리고 쓰러지거나 우는 모습 금지,
#   비난 캐리커처·악역 인물 금지(문제는 크기·자세 대비라는 구조 은유로만), 실존 인물 묘사 금지, 결말 컷은 밝고 안전하게.
#
# ── 스타일 블록 A (스틱맨 개념 컷 공용 — soc 공용) ──
# hand-drawn stick figure comic panel, black ink on clean white paper, thin uniform line weight,
# xkcd / whiteboard-marker doodle style, minimalist line art, no shading, no gradients, flat,
# charming educational. The recurring stick-figure character: plain round circle head, simple dot
# eyes, stick arms and legs, exactly five fingers where hands are drawn. Exactly one restrained
# accent color, teal, used only where the prompt says; everything else pure black and white.
# absolutely no text, no letters, no numbers, no words, no speech bubbles, no captions, no labels,
# no symbols anywhere in the image. NOT 3D, NOT photorealistic, NOT glossy render, NOT digital
# painting, NOT anime. Landscape 4:3, single panel, generous white space.
#
# ── 스타일 블록 T (만화 컷 공용 — 말풍선 하이브리드, 「당연한 것들의 역사」) ──
# Hand-drawn stick figure comic panel, black ink lines on warm off-white paper,
# exactly one accent color: teal, used sparingly where the prompt says.
# Absolutely NO text, NO letters, NO numbers, NO speech bubbles, NO captions anywhere.
# Characters ACT like they are talking: open mouth (small oval), expressive hand gestures.
# All stick figures are gender-neutral basic form (no hair, no skirts); variety comes from
# props only: round glasses, a small satchel, a flat cap. NO flags, NO banners, NO picket
# signs with any writing (blank boards only if needed), NO weapons, NO farming tools held
# as tools, NO fighting, NO handcuffs, NO crying faces, NO real historical persons.
# Historical scenes show working people only SMALL and FAR AWAY (distant silhouette-like
# simple figures), never close up, never collapsed, never miserable poses — calm and
# composed only. No villain characters anywhere. Keep the upper third of the panel
# mostly empty white space above the characters' heads (the app overlays Korean speech
# bubbles there). Main subjects centered horizontally. Simple, charming, educational
# middle-school comic. 4:3 landscape panel.

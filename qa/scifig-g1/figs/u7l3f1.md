# u7l3f1 검산 메모: 태양풍과 지구

- 자리: u7l3 정리 카드 3 '지구로 부는 바람'의 자세히, '지구에서 생기는 일' 문단 뒤.
- 근거: 태양 활동이 지구에 미치는 영향(지구 둘레의 오로라, 인공위성, 무선 통신, 정전). 그래픽 감사(2026-11-15) "지구에 생기는 일 셋이 글자 칩뿐이고 레슨 어디에도 지구 쪽 그림이 없다".
- 그리는 법: 태양은 실사(`public/photos/sun_whitelight.jpg`, NOIRLab CC BY 4.0, 원판 가운데 (905, 855) 반지름 760px)를 왼쪽 가장자리에 크게 걸친다. 지구는 `public/textures/earth.jpg`(Solar System Scope, CC BY 4.0)를 입힌 공을 태양 쪽(왼쪽)에서 비춘다. 태양풍과 이름, 칩은 SVG.

## 담은 과학 사실
1. 태양풍은 태양에서 나오는 입자의 흐름이다(입자 점이 줄지어 지구 쪽으로). 위아래 두 줄은 지구의 두 극 쪽으로 휘어 들어간다(오로라가 극지방에 나타나는 까닭을 그림으로만 보인다. 자기권은 교과 밖이라 그리지 않았다).
2. 오로라는 두 극을 둘러싼 고리(위도 약 67°)로 나타나고 밤 쪽에서 밝다(낮 쪽은 옅게). 고리 위로 옅은 커튼.
3. 지구는 태양 쪽 절반이 낮, 반대쪽이 밤이다. 자전축은 화면에서 18° 기울였다(그림에서만 정한 값).
4. 인공위성 고장(번개 표시), 아래 줄은 랩의 '그때 지구는' 칩과 같은 이름과 그림: 넓은 오로라(오로라 띠), 통신 장애(안테나와 ×), 정전(송전탑).
5. 크기와 거리는 실제 비율이 아니다(태양은 가장자리만, 위성은 크게).

# u4l6f1 검산 메모: 기체를 계속 냉각할 때의 온도와 입자 배열(u4l5f1의 거울)

- 자리: u4l6 열에너지를 방출하는 상태 변화, 정리 카드 0 '열에너지를 방출하는 변화'의 자세히, '왜 그럴까요?' 문단 뒤.
- 근거: 냉각 곡선과 구간별 입자 모형의 흔한 구도. 그리는 코드는 `lib/phasecurve.js`(mode "cool").

## 담은 과학 사실
1. 내리기(기체) → 평평(액화, 긴 구간) → 내리기(액체) → 평평(응고, 짧은 구간) → 내리기(고체). 평평한 구간은 완전히 수평, 온도는 오르지 않는다.
2. 열에너지 화살표는 나가는 쪽(아래)으로 처음부터 끝까지 끊기지 않는다. 색은 들어갈 카드의 색(#5AA2F8). 흡수와 방출을 빨강과 파랑으로 가르는 범례는 만들지 않았다
   (이 레슨의 만화와 카드 1, 2는 '방출하면 주변이 따뜻'을 빨강으로 칠해 색의 뜻이 다르다).
3. 입자 창: 기체, 기체와 액체가 함께, 액체, 액체와 고체가 함께, 고체. 규칙은 u4l5f1과 같다.
4. 물질 이름, 숫자, 과냉각 굴곡 없음.

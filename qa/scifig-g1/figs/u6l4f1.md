# u6l4f1 검산 메모: 샤를 법칙을 입자로(0, 20, 80 ℃)

- 자리: u6l4 정리 카드 1 '입자로 보면'의 자세히, '온도와 입자' 문단 뒤. 조사 표는 개념 스텝의 메모 뒤도 적었으나, 문제 [6](데울 때 달라지는 것)의 답을 그대로 보여 주므로 정리 카드의 자세히에 두었다(조사 5절 6번의 권고).
- 근거: 책 213쪽 그림 Ⅵ-7. 값은 랩(dipLab, chartLab)과 같다: 0 ℃ 28.0 mL, 20 ℃ 30.0 mL, 80 ℃ 36.0 mL.
- 그리는 법: SVG, 주사기는 공용 `lib/syringe.js`. 입자 색과 꼬리는 랩 `syringe.ts`의 식을 그대로: 색상 205 + (t/80)·180(파랑 → 보라 → 주황), 빠르기 0.55 + (√((273+t)/293) − 0.965)·6.2.

## 담은 과학 사실
1. 기둥 높이 140, 150, 180px(28 : 30 : 36, 코드가 확인). 온도가 2배라고 부피가 2배가 아니다.
2. 입자 수 12개와 크기는 셋 다 같고 꼬리(빠르기)만 다르다: 5.1, 7.1, 12.6px(0.55 : 0.77 : 1.37).
3. 바깥에서 누르는 힘 화살표는 셋 다 같은 길이(압력 일정). 속 압력이 커졌다고 쓰지 않았다.
4. 부딪힘 표시는 셋 다 3개, 크기만 온도에 따라 크게('세게'). 뜨거운 쪽에 수를 더 그리지 않았다.
5. 피스톤은 자유롭게 움직인다. 같은 막대라 부피가 클수록 누르개가 높다. 가장 줄어든 0 ℃에도 누르개는 손가락 걸이 위에 남는다.

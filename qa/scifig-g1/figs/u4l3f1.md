# u4l3f1 검산 메모: 상태 변화 여섯 이름 지도

- 자리: u4l3 개념 '상태 변화의 이름, 방향이 정해요'의 term 승화 뒤, note(성질은 그대로) 앞. 바로 뒤의 이름 랩 앞에서 여섯 이름을 한 장에 묶는다.
- 근거: 책 127쪽 그림 Ⅳ-7, 133쪽 중단원 정리의 지도. 구도(세 칸 한 줄)는 책을 따르되 그림은 새로 그렸다.
- 그리는 법: SVG(얼음 조각, 물방울, 유리병을 그라데이션과 반짝임으로).

## 담은 과학 사실
1. 이름과 방향이 정확히 짝: 융해 고체 → 액체, 응고 액체 → 고체, 기화 액체 → 기체, 액화 기체 → 액체, 승화는 고체 → 기체(위 호)와 기체 → 고체(아래 호) 두 방향 모두.
2. 기체 칸은 눈에 보이지 않는 수증기라 마개를 닫은 빈 병만 그렸다. 흰 김이나 구름을 그리지 않는다(김은 액화한 물방울).
3. 입자는 그리지 않았다(물은 융해와 응고에서 부피 예외라 u4l4의 일반 규칙과 부딪힌다).
4. 화살표 색은 정리 카드와 만화 마지막 컷의 짝 색: 융해·응고 #4E9BF5, 기화·액화 #F0705E, 승화 #8A6BFF. 흡수, 방출의 뜻은 색에 싣지 않았다.
5. 이 레슨의 분류와 문제에 나오는 예(버터, 이슬, 끓는 물 등)는 그림에 넣지 않았다.

# u4l5f1 검산 메모: 고체를 계속 가열할 때의 온도와 입자 배열

- 자리: u4l5 열에너지를 흡수하는 상태 변화, 개념 [3]의 용어 카드 '열에너지의 흡수' 바로 뒤, 메모("온도가 멈춰 있는 동안에도 열에너지는 계속 들어와요") 앞.
- 근거: 책 139쪽 그림 Ⅳ-9(구도만: 위 그래프, 아래 입자). 이어진 띠 대신 구간마다 창 하나.
- 그리는 코드: `lib/phasecurve.js`(냉각 곡선 u4l6f1과 공용).

## 담은 과학 사실
1. 오르기(고체) → 평평(융해) → 오르기(액체) → 평평(기화) → 오르기(기체). 평평한 구간은 완전히 수평(조금이라도 오르면 '천천히 오른다' 오개념).
2. 온도는 어디서도 내려가지 않는다. 기화 구간(86px)이 융해 구간(50px)보다 길다.
3. 열에너지 화살표(이 레슨 흡수 카드 색 #FF8A5C)가 시간축 처음부터 끝까지 끊기지 않는다. 평평한 구간에서도 들어온다.
4. 입자 창: 고체(격자), 고체와 액체가 함께, 액체(이웃과 닿을 만큼 가깝지만 줄 없음), 액체와 기체가 함께(아래에 액체, 위에 꼬리 단 기체 입자), 기체.
   평평한 구간의 창에는 두 상태가 함께 있다. 같은 상태 안에서는 온도가 높을수록 흔들림 표시가 크다. 입자 크기는 모든 창에서 같다(반지름 3.9px).
   기체 창은 한 부분을 크게 본 창이라 입자가 적게 보인다.
5. 쓰지 않은 것: 물질 이름, 0 ℃와 100 ℃, 녹는점과 끓는점(중1 미도입), 과열과 과냉각 굴곡, (가)~(라) 구간 기호(문제 그림과 겉모양을 다르게).

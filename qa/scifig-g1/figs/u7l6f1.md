# u7l6f1 검산 메모: 달이 도는 길은 기울어 있다

- 자리: u7l6 정리 카드 0 '일식'의 자세히, '왜 매달 일어나지 않을까요' 문단 뒤.
- 근거: 책에 이 설명의 그림은 없다(관련: 253쪽 그림 Ⅶ-10의 한 평면 배치). 앱 글 "약 5° 기울어 있어서 대부분의 삭에는 달의 그림자가 지구의 위나 아래로 비껴가요"를 그림으로 옮겼다.
- 그리는 법: 지구와 달은 실사 질감 공(Solar System Scope, CC BY 4.0)을 왼쪽 햇빛으로 비춘 입체, 길과 그림자와 글자는 같은 직교 사진기로 투영한 SVG. 사진기는 거의 옆에서 8° 위.

## 담은 과학 사실
1. 태양은 왼쪽, 햇빛은 오른쪽으로. 지구가 태양을 도는 면을 옅은 띠로, 태양과 지구를 잇는 선을 점선으로.
2. 기울기는 16°로 과장하고 그림 안에 "기울기는 실제(약 5°)보다 크게 그렸어요".
3. 달은 위에서 보아 시계 반대: 사진기 쪽(가까운 쪽) 길에서 왼쪽 → 오른쪽(화살촉).
4. (가) 높낮이 축이 태양 쪽: 삭은 면에서 +25.4px, 망은 −25.4px(한 판이 기울었으니 반대쪽, 코드가 계산). 달 그림자 끝은 지구 위 꼭대기(18px)보다 7px 넘게 위, 망의 달 윗가(−20.5px)는 지구 그림자(반지름 13.1px) 밖.
5. (나) 길이 면을 지나는 두 곳이 태양 쪽: 삭과 망이 면 위(0px). 달 그림자 끝이 지구에 닿고(일식), 망의 달은 지구 그림자 속(월식, 어둑한 구릿빛으로 칠함).
6. 크기 비는 실제 비: 달 반지름 = 지구의 0.27배, 달 자리의 지구 본그림자 반지름 = 지구의 0.73배(달 지름의 약 2.7배). 거리만 줄였다.
7. 그림자는 태양 반대쪽으로 좁아지는 꼴(달 그림자는 지구 거리 무렵에서 끝).
8. (가)와 (나)는 한 해 가운데 다른 때: 제목을 '대부분의 때', '한 해에 두 번쯤 오는 때'로 했다(길이 달마다 흔들린다고 읽히지 않게).

# u5l7f2 검산 메모: 같은 빠르기로 도는 회전목마

- 자리: u5l7 정리 카드 0 '힘의 방향과 운동'의 자세히, '놀이공원에서' 문단 뒤.
- 근거: 운동 방향과 수직으로 힘을 받는 대관람차와 회전목마. 위에서 본 구도는 새로 잡았다.
- 그리는 법: 회전판, 기둥, 마차는 입체(위에서 내려다본 직교 사진기), 길과 화살표와 글자는 SVG.

## 담은 과학 사실
1. 위에서 보아 시계 반대로 돈다. 고정된 마차 자리 하나를 같은 시간 간격(90°마다)의 네 자리에 그렸다(말이 오르내리는 움직임은 넣지 않았다).
2. 초록 운동 방향은 원에 접하고 네 자리 모두 같은 길이(빠르기 일정), 같은 회전 방향.
3. 빨간 힘은 중심을 향하고 네 자리 모두 같은 길이. 운동 방향과 수직(코드가 내적 0으로 확인).
4. 바깥을 향하는 화살표(원심력)는 없다.

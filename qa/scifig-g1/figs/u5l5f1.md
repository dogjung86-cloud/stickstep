# u5l5f1 검산 메모: 마찰력, 맞닿은 면을 크게 확대하면

- 자리: u5l5 마찰력, 정리 카드 0 '마찰력'의 자세히, '왜 생길까요' 문단 뒤(unit5v5parts.ts).
- 근거: 끄는 힘과 마찰력의 화살표 자리(마찰력은 맞닿은 면에서 반대 방향). 확대 그림은 앱 글 "크게 확대하면 울퉁불퉁해요"를 그림으로 옮겼다.

## 담은 과학 사실
1. 나무판 위 나무 도막을 힘 센서로 끄는데 아직 움직이지 않는다: 끄는 힘(파랑, 줄을 맨 점에서 오른쪽)과 마찰력(빨강, 맞닿은 면에서 왼쪽)의 길이가 같다(44px).
2. 마찰력은 맞닿은 면에서 시작하고 끄는 힘과 정반대.
3. 확대 그림: 위는 도막 아랫면, 아래는 판 윗면. 둘 다 매끈한 무작위 굴곡(같은 모양의 반복이나 톱니가 아니다). 도막을 판 위에 내려놓듯 위 면을 내려 가장 높은 돌기끼리 닿게 했고,
   맞닿은 곳은 세 곳뿐, 나머지는 틈이 비어 있다. 닿은 곳마다 작은 빨간 화살표(왼쪽).
4. 도막이 판에 박히거나 판이 휘지 않는다. 입자 크기의 그림이 아니다(입자라는 말을 쓰지 않는다). "아주 매끈하면 마찰력이 없다"는 뜻을 주지 않는다.

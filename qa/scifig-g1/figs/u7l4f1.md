# u7l4f1 검산 메모: 천구에 그린 별의 하루 길

- 자리: u7l4 개념 '자전과 일주 운동'의 term 천구 뒤, note(반대 방향) 앞.
- 근거: 책 245쪽 그림 Ⅶ-6(천구 도해)과 그림 Ⅶ-7 아래 돔 삽화. 구도는 새로 잡았다.
- 그리는 법: 둥근 땅과 관측자는 입체로 굽고(직교 사진기), 천구 유리와 별의 길은 같은 사진기로 투영한 SVG.
  - 별의 방향 s(δ, H)는 u7l4f2와 같은 식(위도 37°). 지평 좌표(북, 서, 위) → 장면(동, 위, 남).
  - 사진기: 방위 160°(남남동) 바깥, 내려다보는 각 14°. 북쪽 원을 천구 안쪽 면으로 보므로 화면에서도 시계 반대로 돈다. 코드가 적위 75° 원의 화면 넓이 부호로 확인한다(음수 = 시계 반대).
  - 앞면(바깥 법선이 사진기 쪽)의 길은 진하게(흰 테), 뒷면은 유리 너머라 옅게.

## 담은 과학 사실
1. 북극성은 정북 고도 37°. 관측자 눈에서 북극성으로 점선 = 자전축 방향(천구 밖으로 화살표).
2. 별의 길 넷: 적위 75°, 55°(북극성 둘레를 돌며 지평선 아래로 지지 않음, 55°는 북쪽 지평선 위 2°까지 내려온다), 0°(정동에서 떠 남쪽 고도 53°를 지나 정서로 짐), −12°(동쪽보다 조금 남쪽에서 떠 고도 41°).
3. 길은 모두 자전축에 수직인 평행한 원. 진행은 동 → 남 → 서, 북쪽은 시계 반대(화살촉은 시간각이 커지는 쪽).
4. 땅의 방위 표지(동, 서, 남, 북)는 계산한 방위에 놓되, 앞면의 길과 13px 넘게 떨어지게 거리만 고른다(동은 0.66 R, 나머지 0.84 R).

## 고른 것
- 조사 메모의 적위 30°(북동에서 떠 천정 가까이를 지나는 길)와 −30°는 뺐다. 이 사진기에서 30°는 북극성 둘레 원과 화면에서 겹치고, −30°는 앞 유리의 낮은 곳이라 땅 위에 그린 선처럼 읽혔다(시험 렌더로 확인). 대신 −12°를 두어 동쪽에서 뜨는 길이 둘(나란함이 보인다).
- 관측자는 앱의 학생처럼 노란 모자, 북쪽을 보고 고개를 든다(실제 크기 비율 아님).

# 중2 Ⅷ 별과 우주 v5 설계 (2026-11-12)

정본(`content/g2/unit8.ts`)의 랩 넷(parallaxLab, starLight3d, starColorLab, balloonUniverse)과 galaxy3d, figTabs는 하나도 쓰지 않는다.
판은 책의 탐구와 해 보기에서 다시 짰다. 레슨마다 랩 둘, 모두 열여섯 개. 뼈대는 `bvFrame`, 무대는 캔버스(`u5Kit`의 캔버스 도구)와 실사.

## 레슨의 차례

도입(opener) → 랩 → 용어 → (랩 → 용어) → 정리 → 문제. g2u8l7은 만화(그대로) → 랩 둘 → 용어 → 정리 → 문제.

## 관행

- 접두: 랩 `.g2u8x-`, 도입 `.opn-g2u8-`. 단원 색은 `--subj-star`.
- 등급 값(시리우스 −1.5와 1.4, 북극성 2.1과 −3.7, 데네브 1.3과 −8.7)은 자연값이다. 거리는 두 등급에서 계산한다.
- 연주 시차 그림은 각도를 크게 과장했다고 무대에 적는다. 수치는 1 pc에 1″의 반비례 그대로다.
- 실사는 `public/photos/star/`의 것만 쓴다(새 발주 없음). 책의 관측 대상 가운데 사진이 없는 것은 같은 종류의 보유 사진으로 바꿨다.
- 별의 표면 온도는 화면에 ℃로 적는다(중2는 켈빈을 배우지 않는다). 계산만 켈빈으로 한다.
- 캔버스 그리기 함수의 dt는 프레임 단위(1이 60분의 1초)다.
- 개념 컷은 그리지 않는다(`output/g2-v5/u8/concept-cuts.md`).

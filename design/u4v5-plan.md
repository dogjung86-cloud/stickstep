## 2. 가져다 쓴 도구와 가져오지 않은 것

- 도구로 쓴 것: 메타볼 무대와 입자 뷰(`ui/matterStage`, `engine/matterSim`, 수치 그대로), 온도 색(`renderers/palette`), 유리 벽 그리기(`ui/labProps`), 뼈대 `bvFrame`.
- 가져오지 않은 것: 옛 랩과 v3 랩의 화면 구성과 진행 흐름. v3 브랜치에서는 책의 실험을 그린 SVG 장면의 배치만 참고했다.

## 3. 이 단원의 규칙

- 판정은 랩마다 하나이고 무대에 남은 것으로 답할 수 있는 것만 묻는다. 영상(`output/video-scripts/u4`)이 문장으로 말하는 것은 판정으로 묻지 않고 결론 문장에 둔다.
- 예측은 `u4Predict`(정오를 매기지 않는다)로 걸고 끝에서 "예측대로"와 "예측과 달리"로 견준다.
- 꾹 누르기는 `u4Hold`(손을 떼면 멈춘다. 키보드는 누를 때마다 0.5초). 시간 막대는 되돌아가지 않는다.
- 액체의 입자 창은 "가깝지만 불규칙하게"(`loose()`), 고체는 가지런한 격자, 기체는 멀리 흩어지게 그린다(세 랩이 같은 규칙).
- 책이 '녹는점, 어는점, 끓는점'을 들이지 않으므로 쓰지 않는다("온도가 일정하다"로만 쓴다).
- 수치(0.50 g → 0.31 g, 12.60 g 등)는 이 랩에서 정한 값이다. 0℃와 100℃는 자연값이다.
- 검사: `bash qa/u4v5-build.sh <폴더>` 뒤 `DIST=<폴더> node qa/check-u4v5.mjs`(서버 없이 개발 모드 번들을 내준다).

## 4. 개념, 정리, 문제

- 개념 스텝("과학 용어 정복하기")은 랩 뒤에 둔다(랩에서 본 것에 이름을 붙인다). u4l3만 이름 랩 앞에 둔다(이름 랩이 용어를 전제한다).
  u4l4에는 새 용어가 없어 넣지 않는다. 컷은 싣지 않고 `output/g1-v5/u4/concept-cuts.md`에 장면을 적는다.
- 정리 카드는 새 랩의 장면과 값으로 다시 쓴다(미니 그림은 지금 단원의 `miniArt`).
- 문제는 랩 뒤 첫 문항이 랩의 장면으로 묻고, 랩의 판정과 같은 물음은 뺀다. 남긴 정본 문항은 `unit4v5.ts`의 `keep()`으로 가져온다.

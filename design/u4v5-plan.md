# 중1 Ⅳ 물질의 상태 변화 v5: 랩과 도입 설계 (2026-11-12)

보는 주소는 `?u4v5`(끄기 `?u4v5=0`). 정본(`unit4.ts`)에서 도입과 랩 스텝만 바꿔 끼운다(`unit4v5.ts`). 만화, 정리, 문제는 정본 그대로다.

## 1. 책의 실험과 랩의 대응

| 레슨 | 책의 개념과 실험 | 지금 랩 | v5 랩(스텝 타입) | 손으로 하는 일 |
|---|---|---|---|---|
| u4l1 | 탐구: 잉크의 확산(비커 바닥에 스포이트), 아세트산의 확산(BTB 방울 접시 가운데에 식초, 뚜껑) | `diffusion`(예측과 버튼, 1.31화면) | `u4InkLab` | 예측 → 잉크 넣기 → 시간 막대 → 식초 떨어뜨리기 → 시간 막대 → 판정 |
| u4l1 | 해 보기: 저울 위 거름종이의 손 소독제(펴 발라야 잘 보인다는 도움말) | `evaporation`(꾹 누르기) | `u4EvapLab` | 예측 → 넓게 펴 바르기와 한 덩이로 올리기를 둘 다 → 꾹 눌러 시간 보내기 → 판정 |
| u4l2 | 세 상태의 특징과 입자 배열(그림 Ⅳ-4) | `matterTemp`(밀기) | `u4TempLab` | 온도 막대, 입자의 눈 버튼 → 판정 |
| u4l2 | 고체, 액체, 기체의 모양과 부피 | `matterShape`(누르기) | `u4ShapeLab` | 상태 셋을 컵과 접시에 옮겨 담기 → 판정 |

| u4l3 | 융해, 응고, 기화, 액화 | `phaseNames`(밀어서 이름 넷, 1.21화면) | `u4NamesLab` | 이름을 주면 그 변화를 온도 막대로 일으킨다(다른 변화를 일으키면 그 자리에서 알려 준다) |
| u4l3 | 해 보기: 뜨거운 물 위의 얼음 접시, 푸른색 염화 코발트 종이 | 없음(문제와 정리 글만 이 실험을 말한다) | `u4WatchLab`(새로 넣음) | 세 곳을 눌러 관찰 → 물방울의 출처 판정 → 종이를 두 곳에 대기 |
| u4l3 | 해 보기: 드라이아이스 컵의 비누막 | `sublimation`(버튼 한 번) | `u4DryIceLab` | 비누막 씌우기 → 예측 → 꾹 눌러 지켜보기 → 판정 |
| u4l4 | 탐구: 올리브유를 얼리기 전후의 질량과 부피 | 없음(문제가 이 실험을 묻는다) | `u4OliveLab`(새로 넣음) | 높이 표시하고 재기 → 예측 → 꾹 눌러 얼리기 → 다시 재기 → 판정 |

## 2. 살린 것과 다시 짠 것

- 살린 것: 메타볼 무대와 입자의 눈(`ui/matterStage`, `engine/matterSim`, 물리 수치 그대로), 가열 곡선의 에너지 모형(`heatCurve.ts`의 구간 값), 그릇 벽 그리기.
- 다시 짠 것: 틀(Ⅱ단원과 같은 `bvFrame`: 질문 한 줄, 도움말 두 줄, 무대 230, 높이 고정 조작 칸 208), 흐름(예측 → 손으로 → 판정 하나 → 결론 한 문장),
  '입자의 눈' 버튼(무대 구석 31px 칩 → 조작 칸의 50px 버튼), 꾹 누르는 버튼(늘 조작 칸 맨 위), 가열 곡선(무대와 그래프를 한 무대 안에 좌우로).
- 판정 없이 남아 있던 v3 재제작본(`sci-u4-v3`)에서는 책의 실험을 옮긴 SVG 장면의 배치를 재료로 썼다(잉크와 접시, 저울, 시계 접시, 드라이아이스, 올리브유, 풍선). 단원 내용 파일과 만화는 가져오지 않았다.

## 3. 이 단원의 규칙

- 판정은 랩마다 하나(입자 모형 랩만 세 번)이고, 무대에 남은 것으로 답할 수 있는 것만 묻는다. 영상(`output/video-scripts/u4`)이 문장으로 말하는 것("입자가 스스로 운동한다", "기체가 되어 날아갔다", "상태가 변하는 동안 온도가 일정하다")은 판정으로 묻지 않고 결론 문장에 둔다.
- 예측은 `u4Predict`(정오를 매기지 않는다)로 걸고, 끝에서 "예측대로"와 "예측과 달리"로 견준다.
- 꾹 누르기는 `u4Hold`(손을 떼면 멈춘다. 키보드는 누를 때마다 0.5초). 시간 막대는 되돌아가지 않는다.
- 책이 '녹는점, 어는점, 끓는점'을 들이지 않으므로 쓰지 않는다("온도가 일정하다"로만 쓴다).
- 수치(0.50 g → 0.31 g 등)는 이 랩에서 정한 값이다. 0℃와 100℃는 자연값이다.
- 검사: `bash qa/u4v5-build.sh <폴더>` 뒤 `DIST=<폴더> node qa/check-u4v5.mjs`(서버 없이 개발 모드 번들을 내준다).

## 4. 도입(opener) 네 장면

| 레슨 | 장면 | 내기(정오 없음) | 손으로 하는 일 | 지금 훅에서 바꾼 것 |
|---|---|---|---|---|
| u4l1 | `u4-lid` | 뚜껑을 열면 먼 친구도 냄새를 맡을까 | 꾹 눌러 뚜껑 열기(가까운 친구 먼저, 먼 친구 나중) | 예측을 조작 앞으로, "냄새 입자"라는 답을 말하지 않음 |
| u4l2 | `u4-spill` | 얼음과 주스를 둘 다 주울 수 있을까 | 얼음 세 조각을 눌러 담고 주스를 눌러 집어 보기 | "얼음도 주스도 물과 같은 입자"라는 말을 뺌(주스는 물만이 아니다) |
| u4l4 | `u4-wrap` | 국그릇의 랩은 어떻게 될까 | 꾹 눌러 기다리기(볼록) → 꾹 눌러 식히기(오목) | 식으면 오목해지는 것까지 손으로 |
| u4l5 | `u4-ramen` | 센 불이면 물이 더 뜨거워질까 | 불을 세 번 키우기(기포는 세지고 온도계는 그대로) | 온도계에 숫자 없음 |

## 랩 8종 설계 (전부 "통찰 1개 + 국면 2~3 + b4Ask 판정")

1. **colorClueLab**(L1) — 정체 모를 즙 2개(밥물·달걀흰자액)에 시약 4종 버튼으로 검사. 베네딕트만
   "뜨거운 물에 담그기" 추가 버튼. 색 변화(CSS 전환)를 단서로 정체 판정. 통찰: **시약마다 반응하는
   영양소가 정해져 있다**. 목표: 시료A 정체·시료B 정체·색 짝 판정.
2. **salivaRaceLab**(L2) — 시험관 (가) 녹말+증류수 vs (나) 녹말+침, 35~40℃ 물에 담그기 버튼 →
   10분 경과(빨리 감기) → 아이오딘 체크·베네딕트 체크. (가) 청람/변화 없음 · (나) 변화 없음/황적.
   통찰: **침(아밀레이스)이 녹말을 엿당으로 바꿨다**. L1의 검출 반응을 도구로 재사용(연계).
3. **foodTripLab**(L2) — 녹말·단백질·지방 토큰 하나씩 골라 소화관 4정거장(입→위→작은창자→흡수구)
   버튼 진행. 정거장마다 "여기서 분해될까?" 판정 → 분해되면 토큰이 쪼개진다(CSS). 통찰: **효소는
   특정 영양소에만 작용**(녹말=입·작은창자 / 단백질=위·작은창자 / 지방=작은창자) + 최종 산물 3종.
4. **heartPumpLab**(L3) — 심장 단면 SVG. 이완/수축 버튼 토글 → 혈액 흐름 + 판막 여닫힘 관찰 →
   "거꾸로 밀어 보기" 시도 버튼 → 판막이 닫혀 막는다. 통찰: **판막 = 일방통행 문**(심방→심실→동맥).
5. **twoLoopsLab**(L3) — 혈액 방울이 되어 좌심실에서 출발, 갈림길마다 다음 정거장 탭(온몸→우심방→
   우심실→허파→좌심방) — 색이 산소량 따라 선홍/암적으로 변함. 통찰: **한 바퀴에 심장을 두 번**,
   온몸순환·허파순환의 역할 분담.
6. **chestModelLab**(L4) — 교과서 호흡운동 모형(컵+고무막+풍선). 고무막 슬라이더(아래로 당기기↕) →
   부피·압력 표시 + 풍선 부풂/쪼그라듦 → "몸 대응" 국면(모형 부위 탭 → 몸 부위 매칭) → 판정.
   통찰: **부피가 커지면 압력이 낮아져 공기가 들어온다**(허파는 스스로 못 움직임).
7. **kidneyFilterLab**(L5) — 콩팥단위 모식 무대. 단계 버튼 3개(여과→재흡수→분비)로 알갱이 칩
   (혈구·단백질·포도당·물·요소)의 이동 관찰. 여과에서 혈구·단백질은 못 빠져나감(크기), 재흡수에서
   포도당 전부 복귀, 분비로 요소 추가. 통찰: **여과는 크기 기준, 재흡수는 필요 기준** — 정상 오줌에
   포도당·단백질이 없는 이유.
8. **bodyTeamLab**(L6) — 조직세포가 주문서를 낸다(포도당·산소 반입 / 이산화 탄소·요소 반출).
   주문마다 담당 기관계 탭 배차 → 순환계 트럭이 배달(SMIL/CSS 이동). 통찰: **넷이 협력해야 세포호흡이
   돌고, 운반은 언제나 순환계**.

## 과학 정확성 가드 (SCI_GUIDE 계승 + 교과서 원문 확정 — 위반 금지)
- **여과는 크기로 거른다**: 혈구·단백질은 못 빠져나감. **포도당·아미노산은 전부 재흡수**(정상 오줌에
  포도당·단백질 없음), 물은 대부분 재흡수, 요소는 분비도 되고 배설된다. 콩팥동맥 요소 농도 > 콩팥정맥.
- **소화효소 특이성**: 녹말=입(침 아밀레이스)·작은창자(이자액 아밀레이스) / 단백질=위(펩신+염산)·
  작은창자(트립신) / 지방=작은창자(라이페이스). **염산은 효소가 아니라 조력자**(펩신 돕고 세균 제거),
  **쓸개즙은 소화효소가 없지만 지방 소화를 돕는다**(간에서 생성·쓸개에 저장). 최종 산물: 녹말→포도당,
  단백질→아미노산, 지방→지방산+모노글리세라이드.
- **순환계가 모든 물질을 운반**: 영양소(소화계→), 산소(호흡계→조직세포), 노폐물(조직세포→ CO₂는
  호흡계·요소는 배설계). 세포호흡 = 영양소+산소 → 물+이산화 탄소+에너지, 주로 **마이토콘드리아**.
- 심장: 심방=받는 곳(정맥 연결)·심실=내보내는 곳(동맥 연결), **심실 벽이 더 두껍고 탄력 강함**.
  판막은 심방-심실·심실-동맥 사이(+정맥 곳곳) — **동맥에는 판막 없음**. 폐동맥=산소 적은 혈액·
  폐정맥=산소 많은 혈액(이름 기준은 심장 출입 방향, 혈액 상태와 별개).
- 혈액: 혈장(대부분 물 — 영양소·이산화 탄소·노폐물 운반) + 적혈구(산소 운반·헤모글로빈·핵 없음·
  오목 원반·수 최다) / 백혈구(보호·최대·핵 있음) / 혈소판(응고·최소·핵 없음).
- 호흡: 허파는 **근육이 없어 스스로 못 움직인다** — 갈비뼈·가로막이 흉강 부피를 바꾼다. 들숨 =
  갈비뼈↑·가로막↓ → 부피↑ → 압력↓ → 공기 in (공기는 압력 높은 곳→낮은 곳). 허파꽈리 = 표면적↑.
- 배설: 단백질 분해 노폐물 **암모니아(독성 강) → 간에서 요소로 전환** → 콩팥. 오줌 길 = 콩팥단위
  (토리→보먼주머니→세뇨관) → 콩팥깔때기 → 오줌관 → 방광 → 요도.
- 영양소: 3대영양소(탄수화물·단백질·지방)=에너지원, 바이타민·무기염류·물은 에너지원 아님. **물이 몸
  구성 성분 중 가장 많음**. 검출 색: 녹말=아이오딘 **청람색** / 당분=베네딕트+**가열** **황적색** /
  단백질=뷰렛 **보라색** / 지방=수단Ⅲ **선홍색**.
- 언어: '확산' 용어 금지(교과서 미도입 — "이동한다"로), 세포막 언급은 소화 필요성 서술까지만.
  큰창자 = 소화 거의 없음·물 흡수(물 대부분은 작은창자에서). 해요체·이모지 금지·'교과서' 단어 금지.
- 어두운 무대 위 라벨 = **흰 글자 + 어두운 할로**(흰 할로 금지 — v2 실사고). 흡수율·비율 수치를
  지어내지 않는다(교과서에 없는 수치는 안 쓴다).

## 만화 스펙 — g2u6l3 「피는 돈다」 (하비의 혈액 순환 논증, 7컷)
과학사 실명 관행(린드·보일·뉴턴·허블·반 헬몬트 선례). '모세혈관' 예언까지 담아 순환 개념을 세운다.
1. 1600년대 영국 — 의사 **윌리엄 하비**. 당시 통설: "피는 간에서 계속 새로 만들어져 몸 끝에서 사라진다."
2. 하비의 의심 — 심장을 열어 보니 **판막**이 온통 한 방향 문. "왜 전부 일방통행이지?"
3. 팔 묶기 실험 — 팔을 묶자 정맥이 손목 쪽부터 부풀었다. 정맥의 피는 **심장 쪽으로만** 흐른다!
4. 결정적 계산 — 심장이 한 시간에 내보내는 피를 어림하니 **몸무게를 훌쩍 넘는 양**. 간이 그만큼 만들 수는 없다.
5. 결론 — "피는 사라지는 게 아니라 **같은 피가 돌고 도는 것**이다!" (순환의 선언)
6. 남은 퍼즐 — 동맥 끝과 정맥 끝이 어떻게 이어질까? 하비는 "**보이지 않는 작은 관**이 있을 것"이라 예언.
7. 예언의 확인 — 하비가 세상을 떠난 뒤 현미경이 **모세혈관**을 찾아냈다. 마지막 컷 용어 카드(순환계).
말풍선(bubbles)은 백로그(화자 머리 실측 관행 필수 — u2v3·g2u5v3과 동일). 이미지 안 글자 금지.

# 중1 Ⅱ 생물의 구성과 다양성, 개념 글 다시 쓰기(v6) 설계 (2026-11-12)

v5(정본)는 랩 열세 판과 문제 서른 개를 새로 만들었고, 개념 스텝 열두 개와 정리 열 개는 2026-08의 v3 글을 이어받아 스물여섯 문장만 고쳤다.
이 판은 그 개념 글과 정리 글만 다시 쓴다. 랩, 문제, 만화는 그대로다. 주소 `?u2v6`을 붙였을 때만 보인다(내용 `src/content/unit2v6.ts`).

## 1. 지금 글의 진단(390×700 화면에서 재고 읽은 것)

재는 도구: `node qa/check-u2v6.mjs base`(빌드한 번들을 서버 없이 연다). 개념 스텝 열두 개의 길이는 1.42~2.23화면이다.

| 무엇이 아쉬운가 | 어디서 | 고치는 기준 |
|---|---|---|
| 한 스텝에 용어가 너무 많다 | u2l5(용어 다섯에 학교 비유 메모), u2l9(다섯 계를 한 화면에), u2l6(넷), u2l10(용어가 아닌 목록 셋에 메모 속 용어 셋) | 용어 카드는 셋 안쪽. 넘으면 스텝을 나눈다(u2l5, u2l9는 둘로) |
| 정의가 문장이 아니라 토막말이다 | "핵막 있음, 세포벽 있음", "단계.", 가운뎃점으로 이은 나열, 느낌표 | 정의는 두 문장 안쪽의 온전한 해요체 문장으로 쓴다 |
| 랩에서 한 일을 받지 않는다 | 머리글 한 줄만 "방금"이라고 하고 정의는 옛 랩 시절의 일반 설명이다 | 랩의 장면과 값, 결론 문장을 받아 쓴다(멈추자 생긴 일, 걸린 세포, 숲 세 칸의 60과 4가지, 검색표의 물음 차례) |
| 한 레슨에 비유가 여럿이다 | u2l5(블록, 계단, 학교), u2l9(왕국, 문지기, 프로필, 열쇠, 입주 신청), u2l10(안전망, 창고), u2l1(벽돌, 서랍) | 레슨에 비유 하나. u2l2는 공장(도입과 짝 잇기 문제가 쓴다), u2l5는 계단(랩), 나머지는 비유 없이 랩의 말로 |
| 만든 사람의 말이 섞였다 | "3종 세트", "+2", "프로필", "열쇠", "눈금의 합작", "부품", "발전소", "시험 단골 함정" | 학생이 처음 읽고 아는 말로. '부품'은 랩의 말인 '구조'로 |
| 사실이 불안한 문장 | 양분을 "태워" 에너지를 만든다 · 라이거는 번식 능력이 없다(암컷은 새끼를 낳은 기록이 있다) · 찍찍이는 도꼬마리에서(본래 일화는 우엉 열매) · 세포를 이으면 70만 km(근거를 찾지 못함) · 부리는 "태어날 때 정해져 평생 변하지 않는다"(새는 자라며 부리도 커진다. 랩은 "타고난 모양 그대로") | 빼거나 랩, 영상 원고와 같은 말로 바꾼다 |
| 영상 원고와 예가 어긋난다 | 수가 많다고 다양한 것은 아니라는 예(글은 논의 벼, 영상은 비둘기, 랩은 숲 세 칸) · 세포막과 세포벽의 구분(영상은 "조절하는 것이 막, 지키는 것이 벽") | 메모의 오개념 한 줄은 영상 원고와 같은 예와 말로 |
| 정리의 '자세히'가 문제의 답을 미리 말한다 | u2l7(거미와 개미), u2l9(박새와 버섯) | 같은 뜻을 다른 예로(고양이와 강아지, 소나무와 버섯) |

## 2. 개념 스텝의 자리(랩 앞인가 뒤인가)

| 레슨 | 자리 | 까닭 |
|---|---|---|
| u2l1 | 랩 뒤 | 칸을 본 뒤 '세포'라는 이름을 붙인다 |
| u2l2 | 랩 앞(둘 다) | 랩의 카드와 판정이 세포막, 핵, 마이토콘드리아, 엽록체, 세포벽이라는 이름으로 묻는다. 겪음은 도입(빵 공장의 세 곳을 멈춘다)이 먼저 준다 |
| u2l3 | 두 랩 뒤 | 손으로 만든 표본과 염색에 이름을 붙인다 |
| u2l4 | 랩 뒤 | 일을 맡겨 본 세 세포에 이름을 붙인다 |
| u2l5 | 랩 뒤, 둘로 나눔 | 공통 네 단계(조직, 기관, 개체) → 동물과 식물이 다른 한 칸(기관계, 조직계). 랩의 판정 차례와 같다 |
| u2l6 | 랩 뒤 | 눈금 셋에 이름을 붙인다 |
| u2l7 | 랩 앞 | 만화가 '변이'를 먼저 겪게 하고 이름까지 붙인다. 랩의 판정과 결론이 '변이'라는 말로 묻는다 |
| u2l8 | 첫 랩 뒤(분류), 둘째 랩 앞(종, 분류체계) | 둘째 랩의 막대에 종에서 계까지의 이름이 붙어 있어 단계 이름을 먼저 알아야 읽힌다 |
| u2l9 | 랩 뒤, 둘로 나눔 | 검색표의 물음 차례대로: 핵막과 원핵생물계, 원생생물계 → 식물계, 균계, 동물계 |
| u2l10 | 랩 뒤 | 용어 카드는 책이 낱말 풀이로 준 셋(멸종, 서식지, 생태통로)만. 혜택, 원인, 방법의 목록은 정리 카드로 옮긴다 |

개념 스텝은 열두 개에서 열네 개가 된다. 나눈 둘째 스텝(u2l5, u2l9)에는 컷이 없다(새 컷은 그리지 않는다. 판정 자료의 개념 컷 목록에 적는다).

## 3. 글의 꼴

- 개념 스텝: 컷(정본 스텝의 첫 블록을 그대로 가져오고 캡션만 새 글에 맞춘다) → 용어 카드 셋 안쪽 → 메모 하나(대표 오개념 또는 낱말 풀이).
- 정리: 카드 두 장(미니 그림은 정본 카드의 것을 가져온다). '자세히'는 소제목 셋(랩에서 본 것 → 예나 까닭 → 헷갈리지 마세요)과 '알고 있나요?' 한 줄.
- 끼우는 법: `remakeUnit(UNIT2_V5, { 레슨: { intro, swap: { concept, recap } } })`. 도입은 `unit2intro.ts`의 `SAMPLES`와 같은 값을 옮겨 적었다.
- 새 글과 어긋나 맞춘 문장은 하나다: u2l2 짝 잇기의 머리글("견학했던 빵 공장"과 "세포 부품". 새 도입은 견학이 아니라 세 곳을 멈춰 본다).

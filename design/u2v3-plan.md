## 과학 가드 (전 레슨)
- 중1 언어: '분자' 금지. 세포 소기관 명칭은 교과서 표기 — **마이토콘드리아**(미토콘드리아 아님!), 세포막·핵·엽록체·세포벽. 액포·리보솜 등 미도입 구조 금지.
- '자연선택'·'진화'·'적자생존' 용어 금지 — "환경에 적합한 변이를 가진 생물이 더 많이 살아남아 자손을 남긴다"(교과서 문형)로만. 개체의 부리는 평생 불변(readonly — 라마르크 차단), 변하는 건 무리의 구성뿐.
- 종의 정의 = "자연 상태에서 짝짓기하여 **번식 능력이 있는 자손**"(노새 = 번식 능력 없음 → 당나귀와 말은 다른 종).
- 5계: 원핵생물계(핵막×·세포벽○·단세포), 원생생물계(핵막○·나머지 아닌 무리 — 다시마처럼 다세포도 있음), 균계(핵막○·세포벽○·광합성×·분해), 식물계(광합성○), 동물계(세포벽×·섭취·운동). 원생·원핵의 광합성 여부 단정 금지("종류마다 달라요").
- 변이 = 같은 종류 사이의 서로 다른 특징 — **다른 종끼리의 차이(거미vs개미 다리 수)는 변이가 아님**(대단원 문제 3의 함정).
- 생물다양성 3층위: 생태계의 다양함 · 생물 종류의 다양함 · (같은 종류 안) 특징의 다양함.
- 감소 원인 4: 서식지파괴(최대)·무분별한 채집과 사냥·외래생물(큰입배스)·기후 변화와 환경오염.
- 현미경: 메틸렌 블루=푸른색(입안 상피), 아세트올세인=붉은색(검정말잎 — 염색 오래 기다림), 덮개유리는 비스듬히(기포 방지), 거름종이로 여분 제거. 염색되는 것 = 유전물질(핵이 뚜렷해짐).
- 표기: 「섬 (가)」·「섬 (나)」(괄호 필수), 식물세포 도해 = 육각형, µm(1 µm = 1 m의 100만분의 1) — 40 µm 안팎이 세포 크기 감각.

## 만화 스펙
- **u2v3l1 「1665년, 작은 방의 발견」**(7컷): 런던 로버트 훅 → 자작 현미경 → 코르크 조각 →
  벌집 같은 작은 방들 → "수도원의 작은 방(cell) 같군" 명명 → 이후 모든 생물에서 세포 발견(양파·잎·피) →
  "너의 몸도 세포로" 마무리 + 용어 카드(세포). 말풍선 하이브리드(bubbles), 이미지 안 글자 금지.
- **u2v3l7 「다윈의 이상한 섬들」**(7컷): 비글호 항해 → 갈라파고스 도착 → 섬마다 거북 등딱지가 다름 →
  새(핀치)의 부리도 섬마다 다름 → "먹이가 다르구나" 관찰 → 씨앗 섬=두꺼운 부리·곤충 섬=가는 부리 →
  "살아남은 새가 자손을 남긴 것" 결론(용어 카드 없음 — 개념 서술만, '자연선택' 금지).

# 중1 Ⅱ 재제작 — 레슨별 스텝 대본 (저작 지시서)

`design/u2-rebuild-plan.md`의 §1·§2를 스텝 단위로 푼 것. `src/content/unit2.ts` 저작의 정본이다.
모든 레슨은 표준 공식 **도입(hook/comic) → 랩 → recap → 문제**를 지킨다.
concept 스텝은 **첫 블록이 반드시 `cut("bio3", "u2lN", …)`**(스틱맨 개념 컷 표준).

## 공통 규약
- 단원 id `u2`, 레슨 id `u2l1`~`u2l10`, 테마 톤 `bio`, `kickerTone: "bio"`.
- 무료: L1·L2·L3 / 프리미엄: L4~L10 (`premium: true`).
- 퀴즈는 레슨당 4문, 순서 = **능동형 먼저**(binSort·order) → mcq/multi/ox. 그림 문제 1개 이상.
- 라벨형 보기((가)(나)·ㄱㄴㄷ·계 이름 나열)는 `shuffle: false`.
- recap 카드 3장, 카드마다 `art: bio3MiniArt("<key>")` + `more`(400~800자, `<b class='rm-h'>` 소제목 2~4개).

# 중1 Ⅵ 기체의 성질: 랩, 도입, 개념, 정리, 문제 재제작(v5) 설계

2026-11-12. 주소 `?u6v5`를 붙였을 때만 보인다(`src/content/unit6v5.ts`가 정본 `unit6.ts`에 기대어 조립한다).
레슨의 id, 제목, 쪽수와 u6l2의 만화는 정본 그대로다.

**방침(같은 날 두 번 넓어졌다).** 처음에는 지금 랩의 무대를 살려 틀만 고쳤다(커밋 77deb38~eadb908). 그 뒤 사용자가 "교과서 분석으로 판을 새로 짜고 싶었다, Ⅱ단원처럼 전부 새로"라고 해서
랩을 교과서에서 다시 뽑아 일곱 판으로 새로 만들었다(a6467ca~2568b84). 처음에 틀만 옮긴 랩 다섯(타이어, 주사기, 방울과 마시멜로, 물중탕, 열기구 꾹 누르기)은 걷었다.
개념 스텝, 정리, 문제도 같은 날 범위에 들어왔다.

| u6l5 `u6TempFixLab` 「온도로 문제를 풀 수 있을까?」 | 해 보기(문제 해결), 달걀, 열기구 그림 | 달걀을 삶는 방법, 풍선 속 공기의 온도 | 끓는 물에 바로 넣으면 금이 간다. 덜 데우면 안 뜨고 안 식히면 안 내려온다 | 바로 넣은 달걀이 터지는 까닭 · 떠오를 때 입자 수 | 데우면 늘고 식히면 준다. 이 관계로 문제를 푼다 | 버너를 꾹 눌러 목표 높이에 맞추는 놀이 대신 방법을 정해 푼다 |

- 그리기 도구는 가져다 썼다: 입자와 충돌 번쩍임 `ui/gasKit`(GasBox), 뼈대 `bvFrame`, 무대 도구 `u6v5/u6Kit.ts`, 세로 주사기와 비커 `u6v5/syringe.ts`.
- 수치는 정본과 같다(뒤의 문제가 묻는다): 보일 24 mL 1기압, 12 mL 2기압, 6 mL 4기압. 샤를 20 ℃ 30.0 mL, 10 ℃마다 1.0 mL. 바닷속 10 m마다 1기압.

## 지킨 규칙

- 한 화면: 무대 230, 조작 칸 208(뼈대 치수 그대로). 무대는 캔버스 하나(346×230 설계 좌표).
- 목표는 한 점이 아니다: 눈금에만 서는 막대, "이상" 조건, 고르기.
- 계기는 꾸미지 않는다: 손바닥이 받는 힘과 벽 충돌 막대는 실제 충돌 수를 흐른 시간으로 나눈 값이다(화면이 느려도 같다).
- 판정의 근거는 무대에 남는다(누른 기록, 기록표와 곡선, 자리마다의 압력, 찍은 점, 땅에서와 구름 높이에서의 입자 수).
- 예측은 정오를 매기지 않는다(도입 넷, 담그기 랩의 첫 질문).
- 수면의 1기압은 "물의 압력"이 아니라 공기의 압력이다. 랩은 "누르는 압력"이라고 쓰고, 개념 스텝이 대기압과 수압으로 나눠 부른다.

## 개념, 정리, 문제

정본에는 개념 스텝이 없었다. 새 판의 레슨은 도입 → 랩 → 개념("과학 용어 정복하기") → 정리 → 문제 차례다.
`unit6v5.ts`의 `after: tail((keep) => [...], 랩의 수)`가 랩 뒤를 새로 짠다(`keep(i)`는 정본의 i번째 스텝을 그대로 쓴다).

| 레슨 | 개념 스텝(용어) | 문제(새로 쓴 것은 굵게) |
|---|---|---|
| u6l1 | 압력, 기체의 압력 | **모두 고르기(타이어에 공기)** → 분류 → 선택형(풍선 그림) → **선택형(1칸과 6칸)** → **OX(한 발과 두 발)** |
| u6l2 | 반비례, 보일 법칙 | 선택형(곡선, 4기압) → **차례 놓기** → 선택형(그래프 고르기) → **선택형(주사기 속 풍선)** → 선택형(추 그림) → **선택형(30 mL, 3기압)** |
| u6l3 | 대기압, 수압 | **선택형(방울 30 m에서 10 m)** → **분류** → 선택형(부레) → 선택형(ㄱㄴㄷㄹ) → **OX(과자 봉지, 틀린 설명)** |
| u6l4 | 샤를 법칙 | **선택형(50 ℃의 부피)** → **모두 고르기** → 선택형(직선 그래프) → 선택형(핫팩 플라스크) → **OX(온도 2배, 틀린 설명)** |
| u6l5 | 없음(새 용어가 없다) | **차례 놓기(열기구)** → 분류(보일과 샤를) → 선택형(드라이아이스) → **선택형(구멍 난 탁구공)** → 선택형(오줌싸개 인형) |

- 새 문제 14개. 랩의 판정과 같은 것을 다시 묻는 문항과 레슨마다 "OX 하나로 끝"이던 구성을 뺐다.
- 스틱맨 컷은 없다. 필요한 컷은 `output/g1-v5/u6/concept-cuts.md`(네 장).
- 시험 풀(`exams/u6*.ts`, 160문항)과의 16자 겹침 0건(`node qa/u6v5-text.mjs overlap`).
- 글 도구 `qa/u6v5-text.mjs`: 내용 파일을 esbuild로 묶어 node에서 읽는다(서버가 필요 없다). overlap, blind(검산용 문제지와 정답표), before-after, lint.

## 걸렸던 곳

- 미리보기 서버가 자리가 없어 개발용 번들을 따로 만들어 본다(`NODE_ENV=development vite build --mode development`).
  이렇게 만들면 정답 표식(`data-ok`, `data-oi`)과 바로 열기(`?open=`)가 살아 있다. 폴더 `.u6v5-dev/`는 git에 넣지 않는다.
- 도입 무대의 클래스는 `opn-<장면 이름>`이다. 그림 묶음의 클래스를 장면 이름과 같게 지으면 겹친다.
- 온도에 따른 입자 색을 색상환의 짧은 쪽으로 돌리면 중간에 초록이 나온다. 파랑에서 보라를 거쳐 주황으로 돌렸다.
- 셸 heredoc으로 스크립트를 넘기면 역슬래시가 한 겹 벗겨지고 길면 잘린다(`\n`이 진짜 줄바꿈이 되어 문법이 깨졌다). 파일로 쓴다.
- 0.1을 곱한 값은 정수와 `===`로 견주지 않는다(60 × 0.1은 6이 아니다. 그래프 랩의 점 판정에서 반올림해 견준다).

## 살린 것과 다시 짠 것

- 살린 것: 입자 물리와 충돌 번쩍임(`ui/gasKit`의 GasBox), 소재(타이어, 주사기, 잠수부 방울, 마시멜로, 물중탕, 열기구), 수치.
- 다시 짠 것: 틀(목표 칩 줄과 리드 문단을 없애고 `bvFrame` 한 화면), 무대 높이(400 → 230), 조작부(무대 안 끌기와 화면 밖 버튼 → 조작 칸의 막대와 버튼), 판정(없음 → 누른 보기에 새기는 판정과 결론 한 문장).
- 수치는 정본과 같다(뒤의 문제가 묻는다): 보일 24 mL 1기압, 12 mL 2기압, 6 mL 4기압. 샤를 20 ℃ 30.0 mL, 10 ℃마다 1.0 mL. 바닷속 30 m 4기압.
  샤를은 교과서 탐구 1에 맞춰 얼음물(0 ℃, 28.0 mL)까지 넓혔다.

## 지킨 규칙

- 한 화면: 무대 230, 조작 칸 208(뼈대 치수 그대로). 무대는 캔버스 하나(346×230 설계 좌표, `u6v5/u6Kit.ts`).
- 목표는 한 점이 아니다: 보일은 1 mL씩 딱 붙는 막대와 "기록하기", 샤를은 10 ℃씩, 방울은 막대의 끝, 열기구는 "구름 높이 이상".
- 압력 막대는 꾸미지 않고 실제 충돌 수로 움직인다(보일은 피스톤과 마주 보는 두 벽의 충돌 수라 부피가 4분의 1이면 4배로 잦다).
- 판정의 근거는 무대에 남는다(벽마다의 충돌 수, 기록표와 곡선, 깊이 눈금, 그래프의 점, 땅에서와 구름 높이에서의 입자 수).
- 예측은 도입에서만 건다(정오를 매기지 않는다). 랩의 판정은 조작으로 본 것을 묻는다.
- 도입은 원리의 이름을 말하지 않는다. 북극곰 장면만 "닿는 넓이가 달라졌다"까지 말한다(뒤의 랩이 기체의 압력만 다루고, 넓이와 압력은 정리 카드가 받기 때문이다).

## 개념, 정리, 문제(범위가 넓어져 더한 것)

정본에는 개념 스텝이 없고 개념 설명이 정리 카드에만 있었다. 새 판의 레슨은 도입 → 랩 → 개념("과학 용어 정복하기") → 정리 → 문제 차례다.
`unit6v5.ts`의 `after: tail((keep) => [...])`가 랩 뒤를 통째로 새로 짠다(`keep(i)`는 정본의 i번째 스텝을 그대로 쓴다).

| 레슨 | 개념 스텝(용어) | 문제(새로 쓴 것은 굵게) |
|---|---|---|
| u6l1 | 압력, 기체의 압력 | **모두 고르기(공기를 넣으면 늘어나는 것)** → 분류 → 선택형(풍선 그림) → **선택형(쇠구슬 페트병)** → **OX(한 발과 두 발)** |
| u6l2 | 반비례, 보일 법칙 | 선택형(곡선, 4기압) → **차례 놓기(누르면 일어나는 일)** → 선택형(그래프 고르기) → **선택형(주사기 속 풍선)** → 선택형(추 그림) → **선택형(30 mL, 3기압)** |
| u6l3 | 대기압, 수압 | **선택형(30 m에서 10 m로)** → 분류 → 선택형(부레) → 선택형(ㄱㄴㄷㄹ) → **OX(과자 봉지, 틀린 설명)** |
| u6l4 | 샤를 법칙 | **선택형(50 ℃의 부피)** → **모두 고르기(데우면 달라지는 것)** → 선택형(직선 그래프) → 선택형(핫팩 플라스크) → **OX(온도 2배, 틀린 설명)** |
| u6l5 | 없음(새 용어가 없다) | **차례 놓기(열기구가 떠오르기까지)** → 분류(보일과 샤를) → 선택형(드라이아이스) → **선택형(달걀)** → 선택형(오줌싸개 인형) |

- 뺀 문항과 까닭: 랩의 판정과 같은 것을 다시 묻는 문항(타이어 OX, "누르면 변하지 않는 것", 마시멜로 OX, "식히면 준다" OX), 분류와 겹치는 ㄱㄴㄷ 문항, 페트병 OX.
  레슨 다섯이 모두 "OX 하나로 끝"이던 구성을 풀었다(OX 셋 가운데 둘은 틀린 설명을 가려내는 꼴이다).
- 개념 글은 랩에서 본 것에 이름을 붙인다("24×1, 12×2, 6×4가 모두 24였죠"). 수면의 1기압이 대기압임을 u6l3 개념 스텝이 말한다(랩의 "방울이 받는 압력"을 받는다).
- 정리 카드는 꼴(카드 두 장, 미니 그림, 자세히의 소제목 셋과 상식)을 지키고 새 랩의 장면과 값으로 다시 썼다. 미니 그림은 지금 단원의 것(`gasMiniArt`)을 쓴다.
- 스틱맨 컷은 없다. 필요한 컷은 `output/g1-v5/u6/concept-cuts.md`(네 장).
- 시험 풀(`exams/u6*.ts`, 160문항)과의 16자 겹침 0건(`node qa/u6v5-text.mjs overlap`). 처음에 한 건("끝을 막은 주사기의 피스톤을 눌렀어요")이 걸려 문장을 바꿨다.
- 글 도구 `qa/u6v5-text.mjs`: 내용 파일을 esbuild로 묶어 node에서 읽는다(서버가 필요 없다). overlap, blind(검산용 문제지와 정답표), before-after, lint.

## 걸렸던 곳

- 미리보기 서버가 자리가 없어 개발용 번들을 따로 만들어 본다(`NODE_ENV=development vite build --mode development`).
  이렇게 만들면 정답 표식(`data-ok`)과 바로 열기(`?open=`)가 살아 있다. 폴더 `.u6v5-dev/`는 git에 넣지 않는다.
- 도입 무대의 클래스는 `opn-<장면 이름>`이다. 그림 묶음의 클래스를 장면 이름과 같게 지으면 겹친다(`opn-u6-ice`는 무대, 곰 묶음은 `opn-u6-ice-bear`).
- 온도에 따른 입자 색을 색상환의 짧은 쪽으로 돌리면 중간에 초록이 나온다. 파랑에서 보라를 거쳐 주황으로 돌렸다.

# 중2 Ⅲ 빛과 파동 v5 설계 (2026-11-12)

교과서(책 94~133쪽)의 해 보기와 탐구를 다시 읽고 판을 처음부터 짰다. 옛 랩(reflectLab, diffuseLab, refractLab, seeLab, mirrorImageLab, opticView, mirrorLens,
objectColorLab, colorMixLab, pixelLab, waveLab, soundLab)의 화면 구성과 흐름은 가져오지 않았다. 가져다 쓴 것은 `ui/lightKit`(광선, 각도기, 레이저, 거울, 눈 그리기)과 `ui/lightFigures`의 미니 그림뿐이다.

## 뼈대
- 랩: `b6Lab.bvFrame` 그대로(질문 한 줄 30, 지금 할 일 두 줄, 무대 230, 조작 칸 208). 공용 부품은 `steps/g2u3v5/lxKit.ts`.
- 무대는 캔버스 한 장, 설계 좌표 346×230을 통째로 줄인다. 광선은 `lightKit.drawBeam`만 쓴다. 손그림은 도입에서만 쓴다.
- 조작은 조작 칸의 미는 막대와 버튼이 기본이다(늘 같은 자리, 48px 이상). 레이저는 무대에서 직접 끌어도 된다.
- 랩마다 스텝 요소에 `data-lx-lab`(랩 이름)과 `data-lx`(국면)를 남긴다. 판정 보기의 정답 표식은 개발 모드에서만 붙는다(뼈대가 한다).

## 레슨의 차례
- l1: 도입 → 반사 실험 → 개념(반사, 입사각과 반사각, 반사 법칙) → 거친 면 실험 → 정리 → 문제
- l2: 도입 → 수조 실험 → 개념(굴절, 입사각과 굴절각) → 동전 실험 → 정리 → 문제
- l3: 도입 → 빛의 길 → 개념(광원, 물체를 보는 과정) → 정리 → 문제
- l4: 도입 → 반투명 거울 실험 → 연장선 → 개념(상, 평면거울의 상) → 정리 → 문제
- l5: 도입 → 거울 관찰 → 개념(볼록 거울, 오목 거울) → 렌즈 관찰 → 개념 b(볼록 렌즈, 오목 렌즈) → 쓰임 → 정리 → 문제
- l6: 도입 → 만화(정본 그대로) → 조명 → 손전등 → 화소 → 개념(빛의 합성, 빛의 삼원색, 화소) → 정리 → 문제
- l7: 도입 → 탁구공 실험 → 개념(파동, 매질) → 파동 재기 → 개념 b(마루와 골, 파장과 진폭, 주기와 진동수) → 정리 → 문제
- l8: 도입 → 소리 분석 → 개념(음파, 소리의 3요소, 파형) → 정리 → 문제

## 과학 가드
- 광학은 계산으로 그린다: 반사는 면의 수직선에 대칭, 굴절은 n = 1.33, 거울과 렌즈의 배율은 m = f / (f − d)(볼록 거울과 오목 렌즈는 f가 음수).
- 화면에 '초점', '실상', '허상'을 쓰지 않는다(책은 상의 겉모습만 말한다).
- 랩 화면에서는 '입사각', '굴절각' 같은 이름을 랩 뒤 개념 스텝에서 붙인다. 랩 안에서는 책의 해 보기처럼 "비춘 빛의 각", "거울 면에 수직인 선"이라고 쓴다.
- 소리는 사용자가 누를 때만 낸다(Web Audio, 실패해도 랩은 끝까지 간다).

## 사용자가 정할 것으로 넘긴 것
- 정반사와 난반사는 책에 없다. 단원 종합 평가가 이 내용을 묻고 있어(l1 은행에 17곳) 랩 하나와 정리 카드 하나로 남겼다. 빼려면 평가 은행도 함께 손봐야 한다.

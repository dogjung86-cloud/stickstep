## 교과서 정본 요약 (미래엔 중2, 198~239쪽)

### 1. 소화와 순환
- **영양소(202~203)**: 탄수화물·단백질·지방·바이타민·무기염류·물 6종.
  3대영양소 = 에너지원(탄·단·지). 단백질은 몸 구성 + 조절 + 에너지원, 지방은 몸 구성 + 에너지원
  (피부밑 지방층 = 체온 유지). 바이타민 = 적은 양으로 조절, 무기염류 = 뼈·이 구성 + 조절
  (칼슘·칼륨·나트륨·철·마그네슘). **바이타민·무기염류는 대부분 체내 합성 불가 → 음식으로**.
  **물은 몸의 구성 성분 중 가장 많다**(운반·체온 조절).
- **검출(204~205)**: 아이오딘-아이오딘화 칼륨 → **청람색**(녹말) / 베네딕트 + **가열(80~90℃)** →
  **황적색**(엿당·포도당 등 당분) / 뷰렛 → **보라색**(단백질) / 수단 Ⅲ → **선홍색**(지방).
  시료 5종 = 증류수(대조군)·밥물(녹말)·양파즙(포도당)·달걀흰자액(단백질)·식용유(지방).
- **소화(206~209)**: 포도당·바이타민·무기염류는 세포막 통과 O, 녹말·단백질·지방은 X →
  **소화 = 큰 영양소를 세포막을 통과할 수 있는 작은 영양소로 분해**.
  소화계 = 소화관(입·식도·위·작은창자·큰창자·항문) + 소화샘(침샘·간·쓸개·이자).
  소화효소는 **특정 영양소에만 작용**.
  - 입/침: 아밀레이스 → 녹말→엿당
  - 위/위액: 펩신(+**염산** — 펩신을 돕고 세균을 죽임) → 단백질 분해
  - 작은창자/이자액: 아밀레이스·트립신·라이페이스, **쓸개즙**(간에서 생성·쓸개에 저장,
    **소화효소 없음**, 지방 소화를 도움)
  - 최종 산물: 녹말→**포도당**, 단백질→**아미노산**, 지방→**지방산 + 모노글리세라이드**
- **흡수(210)**: 작은창자 안쪽 벽 = 주름 + **융털** → 표면적 ↑ → 효율적 흡수.
  융털 속에 **모세혈관·암죽관** 분포. 흡수된 영양소는 **심장을 거쳐** 온몸 조직세포로.
  큰창자 = 소화 작용 거의 없음, 주로 **물** 흡수 → 찌꺼기는 대변.
- **순환(212~217)**: 순환계 = 심장 + 혈관 + 혈액.
  심장 = 2심방 2심실. **심방=받아들임(정맥 연결)·심실=내보냄(동맥 연결)**, 심실 벽이 더 두껍다.
  **판막**은 심방↔심실, 심실↔동맥 사이 → 역류 방지. 혈액은 심방→심실→동맥 한 방향.
  혈관: 동맥(두껍고 탄력 강함) · 모세혈관(벽이 매우 얇음, 조직세포와 물질 교환) ·
  정맥(동맥보다 얇고 탄력 약함, **판막 있음**).
  혈액 = 혈장(대부분 물, 영양소·이산화 탄소·노폐물 운반) + 혈구.
  적혈구(수 최다, **핵 없음**, 가운데 오목한 원반, **헤모글로빈**, 산소 운반) ·
  백혈구(**가장 큼**, 모양 일정하지 않음, **핵 있음**, 보호 작용) ·
  혈소판(**가장 작음**, 모양 일정하지 않음, 핵 없음, 혈액응고).
  **온몸순환**: 좌심실→대동맥→온몸 모세혈관→대정맥→우심방.
  **허파순환**: 우심실→폐동맥→허파 모세혈관→폐정맥→좌심방.

### 2. 호흡과 배설
- **호흡(222~225)**: 호흡계 = 코·숨관·숨관가지·허파. 허파는 수많은 **허파꽈리** → 표면적 ↑.
  허파는 **근육이 없어 스스로 못 움직인다**. 흉강 = 갈비뼈 + 가로막.
  **들숨**: 갈비뼈 ↑ · 가로막 ↓ → 흉강·허파 부피 ↑ → 허파 내부 압력 ↓ → 공기 들어옴.
  **날숨**: 갈비뼈 ↓ · 가로막 ↑ → 부피 ↓ → 압력 ↑ → 공기 나감.
  모형: 플라스틱 컵=흉강, 빨대=숨관, 작은 고무풍선=허파, 고무 막=가로막, 컵 속 공간=흉강.
  기체 교환 — 허파꽈리→모세혈관(산소), 모세혈관→허파꽈리(이산화 탄소);
  모세혈관→조직세포(산소), 조직세포→모세혈관(이산화 탄소).
- **배설(226~229)**: 단백질 분해 → **암모니아(독성 강함)** → **간에서 요소로** → 콩팥 → 오줌.
  배설계 = 콩팥·오줌관·방광·요도. 콩팥 = 겉질·속질·깔때기. **콩팥단위** = 토리 + 보먼주머니 + 세뇨관.
  **여과**(토리→보먼주머니): 포도당·아미노산·무기염류·요소·물 등 작은 물질.
  **혈구·단백질은 크기가 커서 여과되지 않는다.**
  **재흡수**(세뇨관→모세혈관): 포도당·아미노산 **전부**, 대부분의 물, 무기염류 등.
  **분비**(모세혈관→세뇨관): 여과되지 않고 남은 노폐물.
  오줌 경로: 콩팥단위 → 콩팥깔때기 → 오줌관 → 방광 → 요도 → 몸 밖.
- **세포호흡(230~231)**: 세포에서 **영양소 + 산소 → 물 + 이산화 탄소 + 에너지**,
  주로 **마이토콘드리아**에서. 에너지는 체온 유지·성장·근육 운동·정신 활동·소리 내기에 쓰인다.
  소화계(영양소)·호흡계(산소) → 순환계 → 조직세포 / 조직세포 → 순환계 →
  호흡계(이산화 탄소)·배설계(요소·물).

## 하이브리드 방침
발주 라스터는 **질감·형태**만 담당하고, **한글 라벨·화살표·수치는 전부 SVG/HTML 오버레이**가 얹는다
(경로도·모식도는 라벨이 본질). 오버레이 좌표계는 이미지 기준 %(정사각 100×100, 4:3 100×75).

## 1. 컨셉과 화면 문법 (사용자 확정)

레퍼런스는 사용자가 처음 만들었던 28초 영상(`KakaoTalk_20260714_003910662.mp4`)의 문법:

- **다크 무대 + 폰 목업 + 폰 아래 카피** 3단 구성. 앱 화면 위에 자막을 얹지 않는다.
- 카피는 **랩 설명이 아니라 앱의 특성**을 말한다. 칩(카테고리) → 헤드라인(강조어만 파랑) → 서브 한 줄.

- 장면 전환은 **쇼츠 스와이프**(xfade `slideup` 0.3s).

## 2. 파이프라인 (4단계)

```
① capture.mjs   앱을 헤드리스로 실제 조작하며 스크린캐스트 → cap/<beat>/f*.jpg + times.json
② rebuild-beats.mjs   cap/ → beats-raw/*.mp4 (자막·손가락 없는 원속 영상, 30fps CFR)
③ compose.mjs   beats-raw를 폰 목업 안에서 배속 재생하며 재촬영 → cap2/c-*/
④ assemble2.mjs  cap + cap2 → beats2/*.mp4 → slideup 연결 → BGM → out/stickstep-marketing-9x16-v3.mp4
```

`make-gifs.mjs`는 ② 뒤에 언제든 돌릴 수 있다(beats-raw에서 다크 무대만 크롭 → out/gifs/).

### 실행

```bash
# 0) app dev 서버를 먼저 띄운다(포트는 .claude/launch.json의 science-app-* 중 하나)
#    ①만 dev 서버가 필요하고 ②③④는 필요 없다.
cd app/marketing/video

PORT=5311 NOCAP=1 NOFINGER=1 node capture.mjs   # 전 비트 (~6분)
node rebuild-beats.mjs
node compose.mjs
node assemble2.mjs
```

- **`NOCAP=1 NOFINGER=1`은 항상 붙인다** — 앱 화면에 굽는 구식 자막 필과 터치 링을 끈다(v3에서 폐기).
- 한 비트만 다시: `BEAT=moon` (capture·compose 공통, 쉼표 구분).
  키 = `intro enter exam notebook heat matter boyle moon laser color comic quiz` (+ compose는 `end`).
- 카피만 고칠 때는 **③④만** 다시 돌리면 된다(2분). 캡처는 그대로 재사용.
- BGM 교체는 `BGM=<mp3 경로> node assemble2.mjs`. 기본값은 코스모 머지 '행성 시대'
  (`public/game/cosmo/bgm-planets.mp3` — 일레븐랩스 자체 발주 자산).

## 3. 반드시 알아야 할 함정 (전부 실사고)

1. **1080×1920은 뷰포트 405×720 × deviceScaleFactor 8/3**로 만든다. CDP `Page.startScreencast`가
   그대로 1080×1920을 뱉는다.
2. **스크린캐스트는 가변 프레임**(정지 구간엔 프레임이 안 온다). `times.json`의 실측 타임스탬프를
   30fps로 리샘플하되 **concat demuxer를 쓰지 말 것** — jpg 고유 1/25s 아래로 duration을 못 줄여
   영상이 늘어난다(2회 사고). 정답은 하드링크로 CFR 시퀀스를 물질화 후 `image2`(rebuild-beats 참조).
3. **CSS 연출은 페이지 로드 순간 시작되는데 녹화는 그 뒤에 시작**돼서 앞 1초가 잘린다.
   → 연출 페이지 전부(`intro/endcard2/compositor`)에 `animation-play-state: paused` +
   `body.go` 게이트를 두고, **rec.start 뒤에** 게이트를 발사한다.
4. **slideup만 켜면 오히려 어색하다.** 각 비트가 "빈 무대 → 폰 rise → 텍스트"로 시작해
   슬라이드 인 직후 빈 화면이 보이는 이중 전환이 된다. → compositor의 `__reveal()`(등장)과
   `__go(rate)`(영상 재생)를 분리하고, compose가 `__reveal → 1.45s 대기 → rec.start → __go`
   순서로 찍어 **완성된 카드가 통째로 슬라이드 인**하게 한다.
5. **헤드라인에 `word-break: keep-all` 필수** — 없으면 "정/복해요"처럼 음절이 꺾인다.
6. **엔드카드 발자국 opacity 하한은 .55** — 스플래시(밝은 배경)의 .3 램프를 그대로 쓰면
   다크 배경에서 갈색 진흙으로 죽는다.
7. **만화·퀴즈 비트는 레슨 미완료 상태로 찍는다** — 완료 레슨은 첫 스텝 CTA에
   "완료한 레슨이에요…" freeNav 배너가 뜬다(랩은 fwd 이동 뒤라 무해).
8. **스플래시 하단에 사업자 정보(전화번호)가 노출**된다 → 브랜드 컷은 스플래시를 찍지 말고
   `endcard2.html`을 쓴다.
9. **시험 비트는 `examScreen("u3")` 직접 진입**으로 찍는다. 지도 노드 탭 경유는
   홈 스텁 콜백이 no-op이라 동작하지 않는다.
10. 걷기 연출은 `homeScreen(..., { walkFrom })` 직접 렌더로 트리거한다
    (`completeLesson` 후 `nav.reset`). 걷기 1회 = 고정 2.1초.
11. 동시 세션이 `src`를 저장하면 HMR 풀리로드로 캡처가 깨진다 →
    capture.mjs가 `@vite/client` 스텁을 물려 둔다(그대로 유지할 것).
